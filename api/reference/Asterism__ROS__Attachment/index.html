    Asterism::ROS::Attachment¶

    The attachment of a sample: sequence, time, publisher GID

    How to use it: Network.

    A reader on rmw_zenoh drops a sample without one. For a received message it is handed to the subscribe block as info.

    Class methods¶

    Asterism::ROS::Attachment.new¶

    new(
  Integer sequence,
  Integer stamp_ns,
  String gid
) -> Asterism::ROS::Attachment

    Make an attachment

    sequence (the number), stamp_ns (nanoseconds since 1970), gid (the GID bytes).

    a = Asterism::ROS::Attachment.new(
  1, 0, "x" * 16)

    Asterism::ROS::Attachment.decode¶

    decode(String? bytes) -> Asterism::ROS::Attachment?

    Read an attachment from its bytes (nil when it is not one)

    nil when fewer than 17 bytes or the GID is cut short.

    a = Asterism::ROS::Attachment.decode(b)
