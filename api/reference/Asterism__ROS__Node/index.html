    Asterism::ROS::Node¶

    A ROS 2 node over a Zenoh session

    How to use it: Network.

    Topics, services and timers hang off this node; closing it ends all of them. Receiving and answering (the subscribe, every and service blocks) run inside Node#poll. Do not wait in a block (a service call or a call to another machine would stall the update): start a call_async and look at done? later.

    node = Asterism::ROS::Node.new(
  @link.conn.session, "fmrb_node")

    Class methods¶

    Asterism::ROS::Node.new¶

    new(
  untyped session,
  String | Symbol name,
  ?namespace: String,
  ?domain: Integer,
  ?enclave: String
) -> Asterism::ROS::Node

    Make a node on a session (it shows in ros2 node list)

    session is an open Zenoh session (conn.session). name is one name (not empty, no "/"; otherwise ArgumentError). namespace: ("/" when left out), domain: (0; ROS_DOMAIN_ID), enclave: ("/"). Declares the node's liveliness at once.

    node = Asterism::ROS::Node.new(
  conn.session, "fmrb_node",
  namespace: "/fmrb")

    Instance methods¶

    Asterism::ROS::Node#poll¶

    poll(?Integer steps) -> bool

    Poll: receive, answer, fire the timers

    Polls the session, answers the service requests that came in, hands the messages to the subscribe blocks and fires the timers that are due. False once the session is closed, true otherwise. steps (8 when left out) is the most times it repeats the session's work (it stops early when nothing is left).

    def on_update
  @node.poll
  100
end

    Asterism::ROS::Node#publisher¶

    publisher(
  String topic,
  untyped type,
  ?qos: String
) -> Asterism::ROS::Publisher

    Make a publisher for a topic

    topic is the topic name ("/chatter"; a relative one goes under the node's namespace), type is the type itself or its ROS name ("std_msgs/msg/String"). qos: (DEFAULT_QOS when left out). Raises Asterism::ROS::UnknownType or ArgumentError for a type that cannot be loaded.

    pub = node.publisher("/chatter",
  "std_msgs/msg/String")

    Asterism::ROS::Node#subscription¶

    subscription(
  String topic,
  untyped type,
  ?qos: String,
  ?depth: Integer
) -> Asterism::ROS::Subscription

    Make a subscription you take messages from

    Messages that arrive wait in it and you take them with each_pending. depth: (16 when left out) is how many can wait, qos: (DEFAULT_QOS). Use subscribe to get them in a block.

    sub = node.subscription("/cmd",
  "std_msgs/msg/String")

    Asterism::ROS::Node#subscribe¶

    subscribe(
  String topic,
  untyped type,
  ?qos: String,
  ?depth: Integer
) { (Asterism::ROS::Message msg, Asterism::ROS::Attachment? info) -> untyped } -> Asterism::ROS::Subscription

subscribe(
  String topic,
  untyped type,
  ?qos: String,
  ?depth: Integer
) -> Asterism::ROS::Subscription

    Receive a topic in a block (from Node#poll)

    |msg, info| is called inside Node#poll for every message (info is an Asterism::ROS::Attachment, or nil). Do not wait in the block. close the returned Subscription to stop. Without a block it is the same as subscription.

    node.subscribe("/cmd",
  "std_msgs/msg/String") do |m, i|
  got(m.data)
end

    Asterism::ROS::Node#service¶

    service(
  String service,
  untyped type,
  ?qos: String,
  ?depth: Integer
) { (untyped request) -> untyped } -> Asterism::ROS::Service

    Serve a service (the block answers requests)

    For every request the block gets it (type::Request) inside Node#poll and returns the answer (a type::Response or a Hash of its fields). depth: (8 when left out), qos: (DEFAULT_QOS). ArgumentError without a block. When the block raises, that request goes unanswered and the exception comes out of poll.

    add = Asterism::ROS.require_type(
  "example_interfaces/srv/AddTwoInts")
node.service("/add", add) do |r|
  { sum: r.a + r.b }
end

    Asterism::ROS::Node#client¶

    client(
  String service,
  untyped type,
  ?qos: String
) -> Asterism::ROS::Client

    Make a client for a service

    Call it with Client#call (waits) or call_async (does not). qos: (DEFAULT_QOS when left out). For occasional calls Node#call makes and keeps a client.

    cli = node.client("/add", add)

    Asterism::ROS::Node#call¶

    call(
  String service,
  untyped type,
  ?untyped req,
  ?request: untyped,
  ?timeout: (Integer | Float)?,
  ?timeout_ms: Integer?,
  **untyped fields
) -> Asterism::ROS::Message

    Call a service once and wait for the response

    node.call("/add", add, a: 2, b: 3). Give the request as field keywords, or a Hash or message positionally or as request:. The time limit is timeout: (seconds) or timeout_ms: (2 s when left out). It makes one client per service name and keeps it. The app waits for the answer, still answering this node's services meanwhile (the subscribe and every blocks do not run). Raises Asterism::ROS::TimeoutError when nothing answers in time, Asterism::Zenoh::ClosedError when the session is closed. If a field of the request is named timeout or timeout_ms, give the request as request: { ... }.

    r = node.call("/add", add,
  a: 2, b: 3)
puts r.sum

    Asterism::ROS::Node#every¶

    every(
  ?(Integer | Float)? seconds,
  ?ms: (Integer | Float)?
) { () -> untyped } -> Asterism::ROS::Timer

    Call a block every so often (from Node#poll)

    every(1.0) { ... } (seconds) or every(ms: 500) { ... }. The first call is one period from now. Runs inside Node#poll. After a long stall it does not fire the missed times at once (it counts from now). Do not wait in the block. Returns a Timer (cancel stops it). ArgumentError without a block or a period, with both, or with one that is not positive.

    t = node.every(1.0) do
  pub << { data: "tick" }
end

    Asterism::ROS::Node#close¶

    close() -> nil

    Withdraw the node and everything made on it

    Publishers, subscriptions, services, clients and timers end with it. Safe to call twice. Returns nil.

    node.close
