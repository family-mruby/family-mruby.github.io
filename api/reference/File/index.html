    File¶

    Reading and writing files (File)

    How to use it: Files & I/O.

    Inherits from: IO

    A subclass of IO; write, puts, print, flush, close and closed? are IO's. Implemented in the Family mruby gems picoruby-fmrb-filesystem (lib/gems/picoruby-fmrb-filesystem/: mrblib/file.rb, ports/esp32/fmrb_filesystem.c) and picoruby-fmrb-io. What CRuby's File has and this one lacks: gets, each_line, readlines, seek, eof?, File.read, File.write, File.binread, File.foreach, File.stat, File.mtime and more. Read with read; to write or read a whole file at once use FmrbFile. A failure is a RuntimeError (no Errno::ENOENT and the like; a missing file, a file that cannot be written and too many open files are told apart by the message only). Writable places are /home and /tmp (/tmp is a small temporary space in RAM).

    Class methods¶

    File.new¶

    new(String path, ?String mode, ?Integer perm) -> File

    Open a file (new)

    mode: "r" (default; read), "w" (truncate and write; created when missing), "a" (append; created when missing), "r+" (read and write; fails when missing), "w+" (truncate, read and write) and "a+" (read, and every write goes to the end; created when missing). A b may be added ("rb+" is "r+"). A mode starting with any other letter opens read-only (no error). read on a "w" or "a" file, and write, puts or print on an "r" file, raise IOError. perm is accepted and ignored.

    RuntimeError ("failed to open file: path") when it cannot open; the reason (missing, no room, too many open) is not told apart. Only 10 files can be open on an ESP32, for all apps together. Close a File when done (File.open with a block does it).

    f = File.new("/home/a.txt", "w")
f.write("hi")
f.close

    File.join¶

    join(*String | Array[untyped] names) -> String

    Join path parts

    Joins the parts with exactly one "/" between them. Parts are Strings or arrays of Strings (nesting allowed); anything else is a TypeError. "" with no arguments.

    File.join("/home", "a.txt")   #=> "/home/a.txt"

    File.basename¶

    basename(String path, ?String suffix) -> String

    The last name of a path

    Ignores trailing "/". suffix (nothing is removed when left out) is cut off the end when it matches (literal text only; CRuby's ".*" does not work). "/" gives "/".

    File.basename("/home/a.txt")          #=> "a.txt"
File.basename("/home/a.txt", ".txt")  #=> "a"

    File.dirname¶

    dirname(String path, ?Integer level) -> String

    The directory part of a path

    level (1 when left out) is how many names to cut off; a negative level is an ArgumentError. A path with no "/" gives ".".

    File.dirname("/home/a.txt")   #=> "/home"

    File.extname¶

    extname(String filename) -> String

    The extension, with its dot

    File.extname("a.txt")   #=> ".txt"

    File.expand_path¶

    expand_path(String path, ?String default_dir) -> String

    Make a path absolute

    Resolves "." and ".." and merges repeated "/". A relative path is based on default_dir (".") put on the app's working directory (Dir.getwd). A leading "~" becomes HOME (ArgumentError when HOME is not set); the "~name" form is an ArgumentError. It does not check the file exists.

    File.expand_path("/home/../tmp/a")   #=> "/tmp/a"

    File.exists?¶

    exists?(String path) -> bool

    Whether a file or a directory is there

    true for a directory too; false when it is missing or cannot be checked (no exception). exists? is the same method under another name.

    File.exist?("/home/a.txt")

    File.file?¶

    file?(String path) -> bool

    Whether it is a regular file

    false for a directory or a missing path.

    File.file?("/home/a.txt")

    File.directory?¶

    directory?(String path) -> bool

    Whether it is a directory

    false for a missing path. "/" and "/mnt" are true.

    File.directory?("/tmp")

    File.size¶

    size(String path) -> Integer

    A file's size in bytes

    RuntimeError ("stat failed for path") when it is missing, not nil; check with File.exist? first. (FmrbFile.size returns nil instead.)

    n = File.size("/home/a.txt")

    File.delete¶

    delete(String path) -> Integer

    Delete a file

    One path only (several cannot be given as in CRuby). Returns 1 when deleted and raises RuntimeError ("cannot delete path") when it cannot: a missing file, a directory (use Dir.delete) or a file still open. unlink is the same method.

    File.delete("/home/old.txt") if File.exist?("/home/old.txt")

    File.unlink¶

    unlink(String path) -> Integer

    Delete a file (same as delete)

    File.unlink("/home/old.txt")

    File.rename¶

    rename(String old_path, String new_path) -> Integer

    Rename or move a file

    Returns 0 when it worked and raises RuntimeError ("cannot rename old to new") when it fails. What happens when the target exists is left to the underlying rename(3) (not checked; delete the target first to be sure).

    File.rename("/home/a.tmp", "/home/a.txt")

    File.open¶

    open(String path, ?String mode) -> File
open(String path, ?String mode) { (File file) -> untyped } -> untyped

    Open a file

    Pass a block: it closes on the way out and returns the block's value. The mode is "r", "w" or "a" ("r" when left out; see File.new for the rest). Reading a missing file raises RuntimeError. There is no File.binread; use read.

    File.open("/home/a.txt", "r") do |f|
  body = f.read
end

    File.exist?¶

    exist?(String path) -> bool

    Whether the file is there

    return unless File.exist?(path)

    Instance methods¶

    File#path¶

    path() -> String

    The path the file was opened with

    f.path

    File#path=¶

    path=(String value) -> String

    Set the recorded path

    Only changes what path returns; the file does not move.

    f.path = "/home/b.txt"

    File#read¶

    read(?Integer length) -> String

    Read the file, or that many bytes of it

    Without an argument it returns all that is left, in memory at once; for a big file pass a length (bytes) and loop. At the end it returns "" and not nil.

    There is no gets (calling it raises NoMethodError). To work line by line, split("\n") what you read.

    body = f.read
head = f.read(16)
body.split("\n").each do |line|
  handle(line)
end

    File#write¶

    write(String str) -> Integer

    Write to the file

    It gives back how many bytes went out.

    f.write("hello\n")

    File#close¶

    close() -> void

    Close it

    Not needed when open was given a block.

    f.close
