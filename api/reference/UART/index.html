    UART¶

    Talk to a device over a serial line (UART)

    How to use it: Hardware Control.

    Written the way upstream PicoRuby's class is. Open with UART.new, send with puts and write, receive with gets and read. Reading never waits: it gives nil until something has arrived, so call it in every on_update. Only write waits until the bytes are on their way.

    The units (unit:) and the pins depend on the board (a unit is the number of UART0 and so on):

    Board Units an app may open Example pins
    Tab5 1, 2, 3, 4 the Grove port, G53 and G54
    NARYA v4 (P4-Nano) 1, 2, 3, 4 the expansion header
    AtomS3R, StickS3 1, 2 Grove
    NARYA v3 2 GROVE 2, 47 and 48
    Linux sim 2 (a stand-in) 47, 48 and others

    UART0 (the console) and NARYA v3's UART1 (the link to the drawing side) are the system's: opening one is an IOError. The browser and the native build have no UART (IOError "not available in this environment"). Pins are guarded by the same table as GPIO: a system pin, or one another app or I2C holds, is an IOError. It cannot be used together with the serial MIDI output: while a MIDI app sends to serial, UART2 and its TX pin are MIDI's, free again once that app ends. The system closes a UART when the app ends.

    The Linux sim's UART is a stand-in: what is written comes back to be read (a loopback). With uart2_in.fifo and uart2_out.fifo in the project directory, it reads from the first and writes to the second.

    # unit and pins are an example
u = UART.new(unit: 1, txd_pin: 53,
  rxd_pin: 54, baudrate: 115200)
u.puts "hello"
line = u.gets   # nil if none yet

    Constants¶

    Name Type What it is
    PARITY_NONE Integer No parity
    PARITY_EVEN Integer Even parity
    PARITY_ODD Integer Odd parity
    FLOW_CONTROL_NONE Integer No flow control (the only one here)
    FLOW_CONTROL_RTS_CTS Integer RTS/CTS flow control (not here)
    WRITE_MAX Integer The most bytes one FmrbUart.write takes

    Class methods¶

    UART.new¶

    new(
  unit: Integer | Symbol | String,
  ?txd_pin: Integer,
  ?rxd_pin: Integer,
  ?baudrate: Integer,
  ?data_bits: Integer,
  ?stop_bits: Integer,
  ?parity: Integer,
  ?flow_control: Integer,
  ?rts_pin: Integer,
  ?cts_pin: Integer,
  ?rx_buffer_size: Integer?
) -> UART

    Open a UART

    unit: is a number (2) or upstream's name (:ESP32_UART2). txd_pin: and rxd_pin: are GPIO numbers; -1 for one of them (receive only, send only). When left out: baudrate: 9600, data_bits: 8, stop_bits: 1, parity: PARITY_NONE, rx_buffer_size: 4096. rts_pin: and cts_pin: are not used.

    Received bytes go into a receive buffer taken while it is open (rx_buffer_size bytes, a power of two from 16 to 16384, in PSRAM). A byte that arrives while it is full is dropped and counted by dropped.

    Wrong arguments are an ArgumentError: an unknown name ("unknown unit"), a unit or pin this board does not have, both pins -1, TX and RX on one pin, a rate outside 300-5000000, a wrong format, the buffer size, anything but FLOW_CONTROL_NONE. When it cannot be opened it is an IOError with the reason: the system's unit ("UART0 is used by the system"), another app has it open, MIDI uses it, a system pin, a line a chip drives (an interrupt line) as TX, a pin in use, none in this environment. The same app opening the same unit again closes the one it had first (that object is closed: reading or writing it is an IOError ("closed")).

    # unit and pins are an example
u = UART.new(unit: 2, txd_pin: 47,
  rxd_pin: 48, baudrate: 115200)

    Instance methods¶

    UART#baudrate¶

    baudrate() -> Integer

    The baud rate

    The rate UART.new asked for, or the one after setmode changed it.

    u.baudrate   #=> 115200

    UART#line_ending=¶

    line_ending=(String line_ending) -> String

    Set the line ending puts adds

    One of "\n" (the default), "\r\n" and "\r"; anything else is an ArgumentError. gets still ends a line at "\n".

    u.line_ending = "\r\n"

    UART#puts¶

    puts(String str) -> nil

    Send a line, adding the line ending

    Adds the line ending (line_ending) unless the string ends with it. Returns nil.

    u.puts "AT"

    UART#setmode¶

    setmode(
  ?baudrate: Integer?,
  ?data_bits: Integer?,
  ?stop_bits: Integer?,
  ?parity: Integer?,
  ?flow_control: Integer?,
  ?rts_pin: Integer?,
  ?cts_pin: Integer?
) -> UART

    Change the rate and the format together

    Changes what is given; but the format (data_bits, stop_bits, parity) goes back to 8, 1 and PARITY_NONE when left out (as upstream). Flow control is FLOW_CONTROL_NONE only. A rate outside 300-5000000 is an ArgumentError.

    u.setmode(baudrate: 9600)

    UART#set_flow_control¶

    set_flow_control(
  Integer flow_control,
  Integer rts_pin,
  Integer cts_pin
) -> nil

    Set flow control (none only)

    Only FLOW_CONTROL_NONE passes; anything else is an ArgumentError.

    u.set_flow_control(
  UART::FLOW_CONTROL_NONE, -1, -1)

    UART#set_format¶

    set_format(
  Integer? data_bits,
  Integer? stop_bits,
  Integer? parity
) -> UART?

    Change data bits, stop bits and parity

    data_bits 5-8, stop_bits 1 or 2, parity one of PARITY_*. All three nil does nothing (returns nil); some nil, or a value out of range, is an ArgumentError.

    u.set_format(8, 1, UART::PARITY_EVEN)

    UART#read¶

    read(?Integer len) -> String?

    Read what has arrived, without waiting

    With len, exactly len bytes, or nil (taking nothing) while fewer have arrived. Without it, everything that has arrived; nil when nothing has. The string is bytes (count it with bytesize).

    head = u.read(4)  # 4 bytes or nil

    UART#readpartial¶

    readpartial(Integer maxlen) -> String?

    Read what has arrived, up to maxlen bytes

    nil when nothing has arrived. Does not wait.

    s = u.readpartial(256)

    UART#getbyte¶

    getbyte() -> Integer?

    Read one byte (nil when none)

    b = u.getbyte

    UART#ungetbyte¶

    ungetbyte(Integer byte) -> nil

    Put one byte back in front of the received ones

    Puts back the low 8 bits; the next getbyte or read gives it. IOError ("rx buffer is full") when the buffer is full. Returns nil.

    u.ungetbyte(0x41)

    UART#bytes_available¶

    bytes_available() -> Integer

    How many received bytes can be read

    n = u.bytes_available

    UART#gets¶

    gets() -> String?

    Read one line up to "\n", without waiting

    The line with its "\n" when one has arrived; nil (taking nothing) until then. The end is "\n" whatever line_ending is. A line longer than the receive buffer never comes (the buffer fills and later bytes are dropped).

    line = u.gets

    UART#write¶

    write(String str) -> Integer

    Send bytes, waiting until they are handed over

    Returns the number of bytes. A long string is sent 4096 bytes at a time.

    u.write("AT\r\n")

    UART#putc¶

    putc(Integer | String ch) -> (Integer | String)

    Send one character or one byte

    An Integer's low 8 bits, or a String's first character (one UTF-8 character). Returns what was given; another type is a TypeError.

    u.putc(0x41)   # "A"

    UART#flush¶

    flush() -> UART

    Wait until what was written has gone out

    Waits one second at most.

    u.flush

    UART#clear_rx_buffer¶

    clear_rx_buffer() -> UART

    Empty the receive buffer

    u.clear_rx_buffer

    UART#clear_tx_buffer¶

    clear_tx_buffer() -> UART

    Empty the send buffer (does nothing here)

    Bytes already handed over cannot be taken back (as upstream's ESP32 port).

    u.clear_tx_buffer

    UART#break¶

    break(?Float | Integer time) -> UART

    Send a break (hold TX low)

    time is seconds as a Float, ms as an Integer (as upstream); 100 ms when left out. Waits that long. Over 10 seconds is an ArgumentError, another type a TypeError. Does nothing on the Linux sim.

    u.break(0.05)   # 50 ms

    UART#dropped¶

    dropped() -> Integer

    Bytes dropped while the receive buffer was full

    The total since it was opened. If it grows, read more often or give a larger rx_buffer_size.

    lost = u.dropped

    UART#close¶

    close() -> nil

    Close it and give the pins back

    Does nothing the second time. Reading or writing after it is an IOError ("closed"). The system closes it when the app ends even without this.

    u.close

    UART#closed?¶

    closed?() -> bool

    Whether it is closed

    u.closed?   #=> false
