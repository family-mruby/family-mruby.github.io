    FmrbSystem¶

    The machine's settings and services

    How to use it: Application.

    Changes the machine's Wi-Fi, BLE, power, clock, audio settings and the PC's settings. Reading the state is on FmrbApp.

    FmrbSystem.set_audio_mute(true)

    Class methods¶

    FmrbSystem.set_wallclock¶

    set_wallclock(
  Integer year,
  Integer month,
  Integer day,
  Integer hour,
  Integer minute,
  Integer second
) -> Hash?

    Set the date and time

    Takes local time and returns the same moment in UTC. Only a device acts on it; Linux and the browser do nothing.

    FmrbSystem.set_wallclock(2026, 9, 1,
                         12, 0, 0)

    FmrbSystem.reboot¶

    reboot() -> void

    Restart the machine

    Restarts the machine. Does not return. Devices only.

    FmrbSystem.reboot

    FmrbSystem.set_audio_mute¶

    set_audio_mute(bool on) -> void

    Mute or unmute the whole machine

    true mutes. Sound keeps playing and only the output goes silent, like a speaker's mute. Saved, so it survives a reboot. External MIDI output is not affected.

    FmrbSystem.set_audio_mute(true)

    FmrbSystem.set_audio_volume¶

    set_audio_volume(Integer step) -> void

    Set the machine's volume (0-10)

    0 is silence, 10 the loudest. Separate from the mute: unmuting comes back at this volume. Saved, so it survives a reboot.

    FmrbSystem.set_audio_volume(5)

    FmrbSystem.preview_audio_volume¶

    preview_audio_volume(Integer step) -> void

    Try a volume without saving it

    For a settings screen's live preview. Saving is audio_conf_saved or set_audio_volume.

    FmrbSystem.preview_audio_volume(v)

    audio_conf_saved() -> void

    Say the sound settings were written

    FmrbSystem.audio_conf_saved

    FmrbSystem.remote_access¶

    remote_access() -> Integer

    Whether the remote control is allowed

    The release build's WiFi remote control. -1: not here (a development build needs no allowing), 0: closed, 1: open (kept across restarts until it is closed).

    FmrbSystem.remote_access
# -1, 0 or 1

    FmrbSystem.remote_access_code¶

    remote_access_code() -> Integer

    The number a PC pairs with

    The six-digit number shown while "Pair a PC" is open; -1 when there is none, -2 when wrong numbers stopped pairing.

    code = FmrbSystem.remote_access_code
sprintf('%06d', code) if code >= 0

    FmrbSystem.set_remote_access¶

    set_remote_access(bool on) -> void

    Open or close the remote control

    Kept until it is closed, across restarts. Closing it also cuts what is connected.

    FmrbSystem.set_remote_access(true)

    FmrbSystem.set_remote_pairing¶

    set_remote_pairing(bool on) -> void

    Start or stop taking new PCs

    New PCs pair only while it is on, with the number it shows. Each start shows a new number and lifts the stop after wrong numbers. PCs already paired work either way.

    FmrbSystem.set_remote_pairing(true)
FmrbSystem.set_remote_pairing(false)

    FmrbSystem.remote_access_paired¶

    remote_access_paired() -> Integer

    How many PCs are paired

    How many PCs are paired with the release build's remote control; 0 in a build that has no such guard. 0 again once revoke_remote_access has forgotten them all.

    n = FmrbSystem.remote_access_paired
FmrbSystem.revoke_remote_access
FmrbSystem.remote_access_paired  #=> 0

    FmrbSystem.ble_settings_window¶

    ble_settings_window(Integer seconds) -> Integer

    Open the window for settings over BLE

    Opens it for that many seconds (0 closes it) and returns the seconds left, 0 when it did not open. While it is open the BLE console may write the WiFi and Asterism settings.

    FmrbSystem.ble_settings_window(300)

    The PC's applications, for the launcher

    Only the native program as the compositor has them; "" elsewhere. A header line, then for mode 0 one "name\tid\ticon" line each. Mode 1 reads them again, mode 2 gives the header only.

    FmrbSystem.settings_page¶

    settings_page() -> Integer

    The settings page asked for

    The native program only. The page in the low two bits (0 Wi-Fi, 1 Bluetooth, 2 Display), the count of the asks above them.

    n = FmrbSystem.settings_page
page = n & 3
# 0 Wi-Fi, 1 Bluetooth, 2 Display
