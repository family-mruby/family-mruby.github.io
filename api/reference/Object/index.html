    Object¶

    A copy for calls with Object as the receiver

    A copy for calls with Object itself as the receiver, as in Object.const_defined?(:X). It does the same as Module#const_defined? (Object is a kind of Module).

    Whether a constant is defined

    Object.const_defined?(:Digest)

    Object.methods¶

    methods() -> Array[Symbol]

    get object method list

    For finding out what an object answers to.

    p obj.methods

    Perform equality comparison

    dup() -> self

    Duplicate object

    A shallow copy: what is inside is shared, not copied.

    b = a.dup

    Object#equal?¶

    equal?(untyped other) -> bool

    Whether it is the very same object

    Asks for the same object, not the same value (unlike ==). Two strings with equal contents that were built separately give false.

    a.equal?(b)

    Object#exit¶

    exit(?Integer status) -> nil

    End the app

    Ends the app; the window is tidied up for you.

    exit

    Object#include¶

    include(*untyped modules) -> nil

    Mix a module in

    A bare constant is not found through the including class in picoruby; write self.class::NAME.

    class Foo
  include Bar
end

    Object#extend¶

    extend(*untyped modules) -> nil

    Add a module to this object alone

    Adds the module to that one object.

    obj.extend(Bar)

    Object#freeze¶

    freeze() -> self

    Make the object unmodifiable

    Returns the object itself. Changing a frozen String, Array or Hash afterwards raises FrozenError. Integer, Symbol, nil, true and false are left as they are (they cannot change anyway). Use it to protect a constant Array or Hash.

    NAMES = ["a", "b"].freeze

    Object#is_a?¶

    is_a?(untyped class_or_module) -> bool

    Check if instance of specified class or module

    Object#loop¶

    loop() { (nil value) -> untyped } -> nil

    Repeat forever

    Do not spin inside an app: the shell can no longer deliver input.

    loop do
  break if done?
end

    Object#raise¶

    raise(?untyped exception, ?String message) -> bot

    Raise an exception

    It ends the app if nothing catches it. Wrap file work in a rescue.

    raise "bad path"
begin
  risky
rescue => e
  Log.info(e.message)
end

    Object#relinquish¶

    relinquish() -> bool

    Give other tasks a turn

    Hands the turn to other tasks; drop it into a long calculation and the screen keeps moving.

    i = 0
while i < 10000
  relinquish if i % 500 == 0
  i += 1
end

    Object#respond_to?¶

    respond_to?(Symbol | String name, ?bool include_all) -> bool

    Whether the object has the method

    name is a Symbol or a String. It does not look at private (true when the method exists). Even without the method it is true when respond_to_missing? says so (include_all is only passed on to that call). Use it for an API that exists on some platforms or builds only.

    GC.respond_to?(:reset_stat)

    sleep(Integer | Float duration) -> Integer

    Wait, in seconds

    Object#sleep_ms¶

    sleep_ms(Integer milliseconds) -> Integer

    Wait, in milliseconds

    Not for use inside an app: outside _spin the tick does not advance and it never returns. Wait with Machine.delay_ms.

    Machine.delay_ms(50)
