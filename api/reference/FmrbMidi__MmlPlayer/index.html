    FmrbMidi::MmlPlayer¶

    Plays a song written in MML

    How to use it: MIDI.

    Call tick on every update to move it along.

    Class methods¶

    FmrbMidi::MmlPlayer.new¶

    new(MIDI::Device device) -> MmlPlayer

    Make the MML player

    @mml = FmrbMidi::MmlPlayer.new(@midi)

    Instance methods¶

    FmrbMidi::MmlPlayer#load_string¶

    load_string(String mml, ?channel: Integer, ?velocity: Integer) -> bool

    Read MML text

    Channel and velocity are keyword arguments (0 and 100 when left out). Anything loaded before is dropped. false when there is nothing to play, with the reason in error. A tempo such as t120 in the text is ignored; use bpm=.

    @mml.load_string("cdefg",
  channel: 0, velocity: 100)

    FmrbMidi::MmlPlayer#add_string¶

    add_string(String mml, ?channel: Integer, ?velocity: Integer) -> bool

    Add another part

    Layers another part on top; unlike load_string it keeps what is already there. channel: and velocity: are 0 and 100 when left out.

    @mml.add_string("egb", channel: 1)

    FmrbMidi::MmlPlayer#load_file¶

    load_file(String path) -> bool

    Read a tune file

    false when it cannot be read, with the reason in error. One line per item; a line starting with # is a comment. bpm 120, loop on, velocity 80, voice triangle, duty 1, volume 100 and program 24 are settings that apply to the parts below; every other line is an MML part, on channels 0, 1, ... in order. voice, duty, volume and program are sent to the device as it loads, so choose the device with device= first.

    @mml.device = @midi
@mml.load_file("/home/a.mml")

    FmrbMidi::MmlPlayer#load_text¶

    load_text(String text) -> bool

    Read tune text in the file format

    load_file for text already in memory. The format and the failure (false, with error) are the same; no part at all gives "no parts in the file".

    @mml.load_text("bpm 90\no4 l4 cdef")

    FmrbMidi::MmlPlayer#total_clocks¶

    total_clocks() -> Integer

    The tune's length in clocks

    A quarter note is 24 and a whole note 96. In ms it is clocks * 2500 / bpm.

    ms = @mml.total_clocks * 2500 / @mml.bpm

    FmrbMidi::MmlPlayer#start¶

    start() -> bool

    Start playing

    Plays from the beginning and returns at once. false when nothing was loaded. Sound starts once tick runs.

    @mml.start

    FmrbMidi::MmlPlayer#stop¶

    stop() -> void

    Stop

    Drops what this player queued and stops the notes that are sounding. Another player of the same app keeps its own queue (pause and device= too).

    @mml.stop

    FmrbMidi::MmlPlayer#pause¶

    pause() -> bool

    Pause

    false when it is not playing.

    @mml.pause

    FmrbMidi::MmlPlayer#resume¶

    resume() -> bool

    Carry on

    What was already queued when you paused (up to 0.3 s) is dropped. false when not paused.

    @mml.resume

    FmrbMidi::MmlPlayer#playing?¶

    playing?() -> bool

    Whether it is playing

    Turns false once the song is read to the end and what this player queued has all played. Another player (of this app or another) still playing does not keep it true.

    draw_bar if @mml.playing?

    FmrbMidi::MmlPlayer#finished?¶

    finished?() -> bool

    Whether it reached the end

    true as well for a tune only loaded, or stopped with stop: it means "not playing". To catch the end, watch playing? turn false.

    @mml.stop if @mml.finished?

    FmrbMidi::MmlPlayer#tick¶

    tick() -> Integer?

    Move the song on -- call it every time

    Nothing plays unless you call it. It returns the wait until the next call, in ms; nil when not playing or over.

    def on_update
  @mml.tick
end

    FmrbMidi::MmlPlayer#next_delay¶

    next_delay(Integer default_ms) -> Integer

    Move the song on and return how long to wait

    Calls tick and returns the shorter of its answer and default_ms. Return it from on_update.

    def on_update
  @mml.next_delay(200)
end

    FmrbMidi::MmlPlayer#bpm¶

    bpm() -> Integer

    The tempo in beats per minute

    n = @mml.bpm

    FmrbMidi::MmlPlayer#bpm=¶

    bpm=(Integer value) -> void

    Change the tempo

    1 to 1000. Notes already handed to the scheduler keep the old tempo.

    @mml.bpm = 120

    FmrbMidi::MmlPlayer#tempo_scale¶

    tempo_scale() -> Float

    How fast to play, against the tempo

    1.0 plays at bpm. Kept apart from bpm.

    s = @mml.tempo_scale

    FmrbMidi::MmlPlayer#tempo_scale=¶

    tempo_scale=(Float value) -> void

    Change the playback speed

    From 0.001 to 100.0, and it can be changed while the tune plays.

    @mml.tempo_scale = 1.5

    FmrbMidi::MmlPlayer#loop¶

    loop() -> bool

    Whether it repeats at the end

    false to begin with; loop on in a file made by load_file sets it. Loading again does not put it back.

    again = @mml.loop

    FmrbMidi::MmlPlayer#loop=¶

    loop=(bool value) -> void

    Set whether it repeats at the end

    When true it carries on from the top at the end.

    @mml.loop = true

    device=(MIDI::Device value) -> void
