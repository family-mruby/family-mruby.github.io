    P5¶

    Draw in the style of p5.js

    How to use it: Processing-style Drawing.

    Make it with @p5 = P5.new(@gfx). It only wraps an FmrbGfx, so you can draw on the same canvas with both. Pick colours with fill and stroke, draw shapes with rect, circle, line, text and so on, then show them with present. background fills the canvas; no_fill leaves outlines only.

    Constants¶

    Name Type What it is
    BLACK Integer black (RGB332)
    WHITE Integer white (RGB332)
    RED Integer red (RGB332)
    GREEN Integer green (RGB332)
    BLUE Integer blue (RGB332)
    YELLOW Integer yellow (RGB332)
    CYAN Integer cyan (RGB332)
    MAGENTA Integer magenta (RGB332)
    GRAY Integer gray (RGB332)
    REPLACE Integer plain overwrite (0)
    ADD Integer brighten where shapes overlap (1)
    XOR Integer invert where shapes overlap (2)

    P5#background¶

    background(Integer color) -> void

    Paint the whole canvas one colour

    Call it at the top of a frame to wipe the last one. With a blend_mode set it blends over instead of wiping.

    @p5.background(FmrbGfx::BLACK)

    P5#present¶

    present() -> void

    Show what has been drawn

    Nothing appears until you call it -- once at the end of a frame.

    @p5.present

    P5#commit¶

    commit() -> void

    Another name for present

    @p5.commit

    P5#fill¶

    fill(Integer color) -> void

    Set the fill colour

    The inside colour of every shape from here on, as a one-byte RGB332 value.

    @p5.fill(FmrbGfx::RED)
@p5.circle(60, 60, 20)

    P5#no_fill¶

    no_fill() -> void

    Draw nothing inside

    Leaves an outline only.

    @p5.no_fill
@p5.rect(10, 10, 40, 20)

    P5#stroke¶

    stroke(Integer color) -> void

    Set the outline colour

    @p5.stroke(FmrbGfx::WHITE)

    P5#no_stroke¶

    no_stroke() -> void

    Draw no outline

    Leaves a filled shape with no outline.

    @p5.no_stroke

    P5#stroke_weight¶

    stroke_weight(Integer w) -> void

    Set the outline thickness

    A thick line is drawn as several thin ones, so it costs more.

    @p5.stroke_weight(3)

    P5#blend_mode¶

    blend_mode(Integer mode) -> void

    Set how colours are blended

    P5::ADD brightens where shapes overlap, P5::XOR inverts; 0 is normal.

    @p5.blend_mode(P5::ADD)

    P5#alpha¶

    alpha(Integer value) -> void

    Set the transparency (does nothing yet)

    It does nothing today. It is here so code copied from p5.js still runs; use blend_mode to overlay.

    @p5.alpha(128)  # no effect

    P5#color¶

    color(Integer r, Integer g, Integer b) -> Integer

    Make a colour from red, green and blue

    Squeezes three 0-255 values into one byte: 8 levels of red and green, 4 of blue.

    c = @p5.color(255, 128, 0)

    P5#bezier¶

    bezier(
  Integer x1,
  Integer y1,
  Integer x2,
  Integer y2,
  Integer x3,
  Integer y3,
  Integer x4,
  Integer y4
) -> void

    Draw a smooth curve

    Start, two pull points, end. It is drawn as 20 straight pieces, so no_stroke leaves nothing.

    @p5.bezier(10, 60, 30, 10,
           70, 10, 90, 60)

    curve(
  Integer x1,
  Integer y1,
  Integer x2,
  Integer y2,
  Integer x3,
  Integer y3,
  Integer x4,
  Integer y4
) -> void

    Draw a curve through points

    Only the stretch between the middle two points is drawn; the outer two just shape the bend.

    @p5.curve(0, 60, 10, 60,
          90, 60, 100, 60)

    P5#begin_shape¶

    begin_shape() -> void

    Start a free shape

    Add corners with vertex, then close with end_shape.

    @p5.begin_shape
@p5.vertex(10, 10)
@p5.vertex(40, 20)
@p5.vertex(20, 40)
@p5.end_shape(true)

    P5#vertex¶

    vertex(Integer x, Integer y) -> void

    Add a corner to the shape

    Called before begin_shape it is silently dropped.

    @p5.vertex(40, 20)

    P5#end_shape¶

    end_shape() -> void

    Finish the free shape

    Pass true to close the shape. Filling needs three corners or more.

    @p5.end_shape(true)

    P5#text¶

    text(String str, Integer x, Integer y) -> void

    Draw text

    P5#translate¶

    translate(Integer tx, Integer ty) -> void

    Shift where things are drawn

    It shifts everything drawn afterwards; pair it with push_matrix to get back.

    @p5.push_matrix
@p5.translate(60, 60)
@p5.circle(0, 0, 10)
@p5.pop_matrix

    P5#rotate¶

    rotate(Integer angle) -> void

    Turn what is drawn

    In radians, about the origin. To spin around an object, translate there first.

    @p5.translate(60, 60)
@p5.rotate(Math::PI / 4)

    P5#scale¶

    scale(Integer sx) -> void

    Scale what is drawn

    A second argument scales the two axes apart; 1.0 is life size.

    @p5.scale(2.0)
@p5.scale(2.0, 0.5)

    P5#push_matrix¶

    push_matrix() -> void

    Remember the current transform

    Always pair it with pop_matrix, or the shift is left behind.

    @p5.push_matrix

    P5#pop_matrix¶

    pop_matrix() -> void

    Go back to the remembered transform

    Doing it with an empty stack is harmless.

    @p5.pop_matrix

    P5#reset_matrix¶

    reset_matrix() -> void

    Clear every transform

    @p5.reset_matrix

    P5#set_pixel¶

    set_pixel(Integer x, Integer y, Integer color) -> void

    Set one pixel

    Not put through the transform -- these are raw screen coordinates.

    @p5.set_pixel(10, 20, c)

    P5#get_pixel¶

    get_pixel(Integer x, Integer y) -> Integer

    Read one pixel's colour

    It waits for an answer, so it is slow. Do not read it inside a loop.

    c = @p5.get_pixel(10, 20)

    P5#image¶

    image(Integer image_id, Integer x, Integer y) -> void

    Draw a loaded image

    The id is one an FmrbGfx load returned; the 4th and 5th arguments scale it.

    @p5.image(id, 10, 20)
@p5.image(id, 10, 20, 2.0, 2.0)
