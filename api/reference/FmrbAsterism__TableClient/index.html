    FmrbAsterism::TableClient¶

    The device side of a game host's table

    How to use it: Network.

    Finds the tables a game host (app "games") has, joins one, asks the member's view and leaves. The Link inside connects again; a host that leaves the network and comes back is handled too.

    Use: make it in on_create; in every on_update, while update is true, collect the answers of the game's own calls (proxy), then call update_view. close in on_destroy.

    Methods the app owns (called by the part): it calls the app by name (no blocks are given). Required: - table_state(path, state) a put of a table's state (a Hash); return what the list keeps (tables[path]) - table_joined(reply) join answered with a token (token is set; the view is asked next) - table_refused(why) join refused (the host's word) or not answered (why nil); table is nil again - table_view(view) the member's view (a Hash) Optional (called when the app has them): - table_link_up(link) after every connect (the subscription and on_join / on_leave are set) - table_link_down(link) a connect failed or the connection went away - table_watch every update while connected, before the states are read - tables_changed(added) a table joined the list (true) or a host's tables left it (false) - table_host_gone the joined table's host left the network - table_host_back that host came back (the view is asked again) - table_view_failed a view got no answer - table_dropped the host does not know this member; without it the part leaves - table_ask_view(px, token) ask the view yourself (px is the table's async proxy); return the Future Leaving or forgetting a table while its join is not answered drops that answer (the next join goes out at once). Any answer of the view, an error too, says the host is there.

    def on_create
  @tc = FmrbAsterism::TableClient.new(
    self, "othello", tag: "othello")
end
def on_update
  if @tc.update
    @tc.update_view
  end
  100
end
def on_destroy
  @tc.close
end

    FmrbAsterism::TableClient.new¶

    new(
  untyped owner,
  String kind,
  ?tag: String?,
  ?app: String,
  ?host_app: String,
  ?retry_ms: Integer?,
  ?wifi_wait_ms: Integer?,
  ?settings: FmrbAsterism::Settings?,
  ?blank: untyped
) -> FmrbAsterism::TableClient

    Make a table client (update connects)

    owner is the app (self). kind is the start of the table names ("othello" finds "/games/othello1" and so on). tag: (kind when left out; the log prefix), app: ("game"; this app's name on the network), host_app: ("games"; the host app to look for), retry_ms: (3000; nil connects once), wifi_wait_ms: (when left out only the ESP32 waits for WiFi; the sim and the browser do not), settings: (FmrbAsterism.settings), blank: (nil; a sample of what the list keeps for a table whose state has not come yet; a copy is stored; mahjong uses {}). For the methods the app owns (table_state and the rest) see the class description.

    @tc = FmrbAsterism::TableClient.new(
  self, "mahjong", blank: {})

    FmrbAsterism::TableClient#update¶

    update() -> bool

    Every update: connect, states, list, join

    While connected it hands the states that came to table_state, looks for tables and collects the answer to a join. Otherwise it connects (the app waits a few seconds when there is no router, as with Link#update). True while connected.

    if @tc.update
  draw_table
end

    FmrbAsterism::TableClient#update_view¶

    update_view(?Integer now) -> void

    Collect the view and ask it when due

    Call it after collecting the game's own answers. Hands an arrived view to table_view, and asks a new one when the member is in a table, none is on its way and it is due. Nothing without a table. now (the current ms when left out) is for tests.

    @tc.update_view

    close() -> nil

    Close for good (on_destroy)

    Closes the Link. It does not leave the table: leave it yourself first when joined.

    @tc.close

    FmrbAsterism::TableClient#proxy¶

    proxy(?String path) -> Asterism::Proxy

    A proxy for the table (or another path) for the game's own calls

    proxy is the joined table, proxy(path) another path. Calls wait call_timeout. For a call that does not wait use proxy.async. Raises Asterism::Disconnected when not connected, ArgumentError without a path (no table joined).

    f = @tc.proxy.async.play(@tc.token, 3)

    FmrbAsterism::TableClient#join¶

    join(String? path, String name) -> String?

    Join the table at path as name

    Sends the call and returns; update collects the answer and calls table_joined or table_refused. Returns nil and does nothing when a join is already on its way or path is nil. When the call could not be sent it returns the error's text (a String) and table is nil again. Call it while connected.

    err = @tc.join(path, "Aki")
show(err) if err
