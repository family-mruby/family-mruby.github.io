    String¶

    A string (UTF-8)

    Positions in length and [] count characters, not bytes; use bytesize, getbyte and byteslice for binary data. + makes a new string each time, so build in a loop with <<. There is no Regexp here.

    Instance methods¶

    String#!¶

    !() -> bool

    Return logical NOT

    A string is always true, so this is always false.

    !"a"  #=> false

    String#*¶

    *(Integer count) -> String

    Repeat string specified number of times

    Handy for a rule or for padding; 0 gives an empty string.

    "-" * 39
"\x00" * 16  # a 16-byte buffer

    String#+¶

    +(String other) -> String

    Concatenate strings

    Every + makes a new string; build up with << inside a loop instead.

    a = "foo" + "bar"

    String#<¶

    <(String other) -> bool

    Check if lexicographically smaller

    "abc" < "abd"  #=> true

    String#<<¶

    <<(String | Integer string_or_codepoint) -> String

    Append string or character code

    It changes the string in place, so it beats +. An integer is appended as a character code.

    buf = ""
buf << "a"
buf << 65  # "A"

    String#<=¶

    <=(String other) -> bool

    Check if lexicographically less than or equal

    "abc" <= "abc"  #=> true

    String#<=>¶

    <=>(String other) -> Integer

    Compare lexicographically. Returns -1, 0 or 1

    Used as the comparison when sorting.

    "a" <=> "b"  #=> -1

    String#==¶

    ==(untyped other) -> bool

    Perform equality comparison

    Compares the contents, not whether they are the same object.

    "abc" == "abc"  #=> true

    String#===¶

    ===(untyped other) -> bool

    Perform equality comparison (for case statements)

    case s
when "quit" then finish
end

    String#>¶

    >(String other) -> bool

    Check if lexicographically greater

    "b" > "a"  #=> true

    String#>=¶

    >=(String other) -> bool

    Check if lexicographically greater than or equal

    "b" >= "b"  #=> true

    String#[]¶

    [](untyped index_or_range) -> (String | nil)

    Get character or substring at specified position

    The position counts characters, not bytes; outside the string it is nil.

    s[0]
s[0, 3]
s[1..2]

    String#[]=¶

    []=(untyped index_or_range, String replacement) -> String

    Replace the character or substring there

    The length may change: one character can become three.

    s[0] = "X"
s[0, 2] = "ab"

    String#__ljust_rjust_argcheck¶

    __ljust_rjust_argcheck(Integer | String width_or_padding) -> nil

    Internal argument check for ljust and rjust

    Internal. Not meant to be called.

    String#bytes¶

    bytes() -> Array[Integer]

    Return byte sequence of string as array

    It builds an array, so it costs on a long string; for one byte use getbyte.

    "AB".bytes  #=> [65, 66]

    String#bytesize¶

    bytesize() -> Integer

    Return the size in bytes, not characters

    Use this for binary data. length counts a Japanese character as one, so the two differ.

    "あ".bytesize  #=> 3
"あ".length    #=> 1

    String#byteslice¶

    byteslice(Integer start, ?Integer length) -> (String | nil)
byteslice(Range range) -> (String | nil)

    Cut out a part by byte offset and byte length

    Returns length bytes from byte start as a new string. Both count bytes. A Japanese character is 3 bytes (UTF-8), so a position from [], slice, length or index (which count characters) lands in the wrong place once the string holds Japanese. Pair it with bytesize and getbyte, which count bytes.

    A negative start counts from the end; a length past the end stops at the end. A start right at the end (bytesize) gives ""; a start past it, or a negative length, gives nil (no exception), so put .to_s before another string method. Cutting inside a character does not stop it: you get the broken bytes.

    Without length you get that one byte (nil from the end on). A range of bytes (2..4) works too.

    s = "あいう"
s.byteslice(3, 3)   #=> "い"
s[1]                #=> "い"
s.byteslice(9, 1)   #=> ""
s.byteslice(10, 1)  #=> nil
rest = s.byteslice(3,
  s.bytesize - 3).to_s

    Return characters of string as array

    String#each_byte¶

    each_byte() { (Integer byte) -> untyped } -> self

    Execute block for each byte

    A block call costs about 0.4ms. On a long string, while with getbyte is faster.

    s.each_byte do |b|
  n += b
end

  handle(l)

    empty?() -> bool

    String#end_with?¶

    end_with?(String suffix) -> bool

    Check if ends with specified string

    There is no Regexp here, so this is how you check a file extension.

    if path.end_with?(".rb")

    String#getbyte¶

    getbyte(Integer index) -> (Integer | nil)

    Get byte value at specified position

    The way to read binary data. nil outside the string.

    b = data.getbyte(4)

    String#setbyte¶

    setbyte(Integer index, Integer byte) -> Integer

    Set the byte value at a position

    There is no Array#pack, so make a "\x00" * n buffer and write the bytes in.

    buf = "\x00" * 4
buf.setbyte(0, 0x12)

    String#include?¶

    include?(String other) -> bool

    Check if contains specified string

    Measured at 1.7ms -- do not call it on every pass of a loop.

    if s.include?("err")

    String#index¶

    index(
  String | Integer substring_or_codepoint,
  ?Integer offset
) -> (Integer | nil)

    Return first position of specified string

    nil when it is not there. The second argument says where to start.

    i = s.index("=")
j = s.index(",", i + 1)

    String#rindex¶

    rindex(String substring, ?Integer offset) -> (Integer | nil)

    Return the last position of a substring

    Returns the character position (a Japanese character counts as 1), or nil when it is not found. offset (the end of the string when left out) is where the search starts; nothing after it is looked at. Strings only (no Regexp, no Integer).

    path.rindex("/")      #=> 8
path.rindex(".", 5)

    String#split¶

    split(?String separator, ?Integer limit) -> Array[String]

    Split by delimiter and return array

    With no argument it splits on whitespace. A limit keeps the rest together -- what you want for a key=value line.

    "a,b,c".split(",")
"k=a=b".split("=", 2)

    String#to_f¶

    to_f() -> Float

    to_i(?Integer base) -> Integer

    to_sym() -> Symbol

    Convert to symbol
