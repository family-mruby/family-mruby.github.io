    Colour Names¶

    The machine shows 256 colours: three bits of red, three of green, two of blue, packed into one byte (RGB332). Anywhere a colour is asked for you can write that byte — 0x1F — but most of them have a name as well, and a name is what keeps a file a person edits a file a person can read.

    The names are the web's, mapped onto the 256 this machine has. Mapping them collapses some (a 3-3-2 grid cannot tell ivory from snow), so the list comes in two parts: 78 names, one per distinct colour, and 23 further spellings that land on a colour already in the list. Both are understood; the 78 are what a picker offers back, and what a file is written with.

    From an app (FmrbColors)¶

    Method
    FmrbColors.by_name("skyblue") The value, or nil when it is not one of ours
    FmrbColors.to_color(str) The same, but "0x1F" and "31" are accepted too
    FmrbColors.to_text(value) Its name, or "0x1F" when it has none. This is what gets written to a file
    FmrbColors.name_of(value) Its name, or nil
    FmrbColors.palette_size / name_at(i) / palette_value(i) Walking the 78, which is how a picker is built
    FmrbColors.shade(colour, avoid = nil) A step darker, or lighter when darker would land on avoid or on the colour itself. The editor's bars are made this way
    FmrbColors.section("editor") That section of the user's colours file, as a Hash

    A name that is not one of ours gives nil rather than a colour. That is deliberate: a typo in a colours file leaves the theme colour in place instead of painting the app black.
