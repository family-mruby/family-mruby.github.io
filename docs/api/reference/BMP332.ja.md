# BMP332

RGB332 の絵 (8 ビット BMP・パレット PNG)

使い方は [ユーティリティ](../utilities.md) のページにあります。

画素は 1 点 1 バイトの RGB332 を上の行から並べた String (幅 x 高さバイト)。透明な点は 0x01。PNG は透明 (α が 128 未満・tRNS) を 0x01 にして読む。幅と高さは 2048 まで。

画面に出すだけなら画素は要らない: FmrbGfx#draw_picture にパスを渡す。

## クラスメソッド

### BMP332.load

<pre class="fmrb-sig"><code>load(<a href="../String/">String</a> path) -&gt; <a href="../Hash/">Hash</a></code></pre>

絵のファイルを画素にする

形は先頭のバイトで見分ける。読めなければ例外。画素は VM に載るので、大きい絵 (256x256 で 64 KB) は VM プールを使う。
```ruby
bmp = BMP332.load("/home/a.png")
w = bmp[:width]
px = bmp[:pixels]
```

### BMP332.parse

<pre class="fmrb-sig"><code>parse(<a href="../String/">String</a> data) -&gt; <a href="../Hash/">Hash</a></code></pre>

絵のバイト列を画素にする

load のファイルの代わりにバイト列を受ける。結果は
{width:, height:, pixels:}。
```ruby
bmp = BMP332.parse(data)
```

### BMP332.save

<pre class="fmrb-sig"><code>save(<a href="../String/">String</a> path, <a href="../Integer/">Integer</a> width, <a href="../Integer/">Integer</a> height, <a href="../String/">String</a> pixels) -&gt; void</code></pre>

画素を PNG か BMP のファイルに書く

パスが .png で終わればパレットの PNG (使った色だけ)、それ以外は
8 ビットの BMP。
```ruby
BMP332.save("/home/a.png", 16, 16,
            px)
```

### BMP332.png_path?

<pre class="fmrb-sig"><code>png_path?(<a href="../String/">String</a> path) -&gt; bool</code></pre>

パスが PNG か

名前の終わりが `.png` (大文字小文字は問わない) なら true。中身は見ない。
`save` が PNG と BMP を分けるのと同じ決め方。
```ruby
fmt = BMP332.png_path?(path) ? "png" : "bmp"
```

### BMP332.encode_png

<pre class="fmrb-sig"><code>encode_png(<a href="../Integer/">Integer</a> width, <a href="../Integer/">Integer</a> height, <a href="../String/">String</a> pixels) -&gt; <a href="../String/">String</a></code></pre>

画素をパレットの PNG のバイト列に

```ruby
png = BMP332.encode_png(16, 16, px)
```

### BMP332.info

<pre class="fmrb-sig"><code>info(?<a href="../String/">String</a> path, ?data: <a href="../String/">String</a>) -&gt; <a href="../Hash/">Hash</a>?</code></pre>

解かずに絵の大きさと形を知る

先頭 (PNG の IHDR、BMP の見出し) だけを読む。結果は
{width:, height:, format: :png か :bmp, bytes: ファイルの大きさ}。無い・読めない絵なら nil。大きすぎる絵もその大きさを答える。パスの代わりに data: でバイト列を渡せる。
```ruby
info = BMP332.info("/home/a.png")
if info && info[:width] <= 48
  ok = true
end
BMP332.info(data: bytes)
```

### BMP332.to_png

<pre class="fmrb-sig"><code>to_png(
  ?<a href="../String/">String</a> path,
  ?data: <a href="../String/">String</a>,
  ?max_width: <a href="../Integer/">Integer</a>,
  ?max_height: <a href="../Integer/">Integer</a>,
  ?max_bytes: <a href="../Integer/">Integer</a>,
  ?max_file_bytes: <a href="../Integer/">Integer</a>
) -&gt; <a href="../Hash/">Hash</a></code></pre>

絵を小さいパレットの PNG に書き直す

PNG か BMP を読み、使った色だけのパレットの PNG に書き直す。中は C
で済み、画素は VM に載らない。バイト列は encode_png(parse の画素)
と同じ。透明は 0x01 の色になる。

結果は {png: バイト列, width:, height:}。断るときは例外でなく
{error: 理由, ...}:

- :too_big (width:, height: つき): max_width か max_height を超える。
  解く前に先頭で断る
- :too_heavy (bytes:): 書いた PNG が max_bytes を超える
- :file_too_large (bytes:): ファイルが max_file_bytes (既定 65536)
  を超える。読まない
- :unreadable: 無い・絵でない・壊れている
- :no_memory: VM プールが足りない

パスの代わりに data: でバイト列を渡せる。`max_width:` `max_height:` は省略すると
2048、`max_bytes:` は省略すると上限なし。
```ruby
r = BMP332.to_png("/home/a.png",
  max_width: 48, max_height: 48,
  max_bytes: 8192)
if r[:error]
  show(r[:error])
else
  FmrbFile.write(out, r[:png])
end
```
