# P5

Draw in the style of p5.js

How to use it: [Processing-style Drawing](../p5.md).

Make it with `@p5 = P5.new(@gfx)`. It only wraps an FmrbGfx, so you can
draw on the same canvas with both. Pick colours with `fill` and `stroke`,
draw shapes with `rect`, `circle`, `line`, `text` and so on, then show
them with `present`. `background` fills the canvas; `no_fill` leaves
outlines only.

<pre class="fmrb-sig"><code>new(<a href="../FmrbGfx/">FmrbGfx</a> gfx) -&gt; P5</code></pre>

### P5#translate

<pre class="fmrb-sig"><code>translate(<a href="../Integer/">Integer</a> tx, <a href="../Integer/">Integer</a> ty) -&gt; void</code></pre>

Shift where things are drawn

It shifts **everything drawn afterwards**; pair it with `push_matrix` to
get back.
```ruby

```

<pre class="fmrb-sig"><code>rotate(<a href="../Integer/">Integer</a> angle) -&gt; void</code></pre>
