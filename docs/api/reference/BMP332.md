# BMP332

RGB332 pictures (8-bit BMP and palette PNG)

How to use it: [Utilities](../utilities.md).

Pixels are a String of one RGB332 byte per pixel, top row first (width x
height bytes); a transparent pixel is 0x01. A PNG's transparency (alpha
below 128, tRNS) reads as 0x01. Width and height up to 2048.

To only show a picture no pixels are needed: hand its path to
FmrbGfx#draw_picture.

## Class methods

### BMP332.load

<pre class="fmrb-sig"><code>load(<a href="../String/">String</a> path) -&gt; <a href="../Hash/">Hash</a></code></pre>

Read a PNG or BMP file into RGB332 pixels

The kind is told from the first bytes. Raises when it cannot be read.
The pixels live in the VM, so a large picture (64 KB at 256x256) takes
the VM pool.
```ruby
bmp = BMP332.load("/home/a.png")
w = bmp[:width]
px = bmp[:pixels]
```

### BMP332.parse

<pre class="fmrb-sig"><code>parse(<a href="../String/">String</a> data) -&gt; <a href="../Hash/">Hash</a></code></pre>

Turn PNG or BMP bytes into RGB332 pixels

load, from the bytes instead of a file. The result is
{width:, height:, pixels:}.
```ruby
bmp = BMP332.parse(data)
```

### BMP332.save

<pre class="fmrb-sig"><code>save(<a href="../String/">String</a> path, <a href="../Integer/">Integer</a> width, <a href="../Integer/">Integer</a> height, <a href="../String/">String</a> pixels) -&gt; void</code></pre>

Write RGB332 pixels as a PNG or a BMP file

A path ending in .png gets the palette PNG (only the colours used); any
other an 8-bit BMP.
```ruby
BMP332.save("/home/a.png", 16, 16,
            px)
```

### BMP332.png_path?

<pre class="fmrb-sig"><code>png_path?(<a href="../String/">String</a> path) -&gt; bool</code></pre>

Whether a path names a PNG

true when the name ends in `.png` (any case); the contents are not
looked at. It is how `save` tells PNG from BMP.
```ruby
fmt = BMP332.png_path?(path) ? "png" : "bmp"
```

### BMP332.info

<pre class="fmrb-sig"><code>info(?<a href="../String/">String</a> path, ?data: <a href="../String/">String</a>) -&gt; <a href="../Hash/">Hash</a>?</code></pre>

A picture's size and kind, without decoding it

Only the head is read (a PNG's IHDR, a BMP's headers). The result is
{width:, height:, format: :png or :bmp, bytes: the file's size}; nil
when it is not there or cannot be read. A picture too large to decode
still gives its size. data: takes the bytes instead of a path.
```ruby
info = BMP332.info("/home/a.png")
if info && info[:width] <= 48
  ok = true
end
BMP332.info(data: bytes)
```

### BMP332.to_png

<pre class="fmrb-sig"><code>to_png(
  ?<a href="../String/">String</a> path,
  ?data: <a href="../String/">String</a>,
  ?max_width: <a href="../Integer/">Integer</a>,
  ?max_height: <a href="../Integer/">Integer</a>,
  ?max_bytes: <a href="../Integer/">Integer</a>,
  ?max_file_bytes: <a href="../Integer/">Integer</a>
) -&gt; <a href="../Hash/">Hash</a></code></pre>

Rewrite a picture as a small palette PNG

Reads a PNG or a BMP and writes it again as the palette PNG of only the
colours used. It is all done in C; the pixels never enter the VM. The
bytes are those of encode_png over parse's pixels. Transparency becomes
the colour 0x01.

The result is {png: bytes, width:, height:}. A refusal is not an
exception but {error: reason, ...}:

- :too_big (with width:, height:): past max_width or max_height,
  refused from the head before anything is decoded
- :too_heavy (bytes:): the PNG written is past max_bytes
- :file_too_large (bytes:): the file is past max_file_bytes (65536
  unless given); it is not read
- :unreadable: not there, not a picture, or broken
- :no_memory: the VM pool ran short

data: takes the bytes instead of a path. `max_width:` and `max_height:`
are 2048 when left out; `max_bytes:` has no limit when left out.
```ruby
r = BMP332.to_png("/home/a.png",
  max_width: 48, max_height: 48,
  max_bytes: 8192)
if r[:error]
  show(r[:error])
else
  FmrbFile.write(out, r[:png])
end
```
