# P5

p5.js 風の書き方で絵を描く

使い方は [Processing 風の描画](../p5.md) のページにあります。

`@p5 = P5.new(@gfx)` で作る。FmrbGfx を包むだけなので、同じ絵に両方から描いてよい。
`fill`・`stroke` で色を決めてから `rect`・`circle`・`line`・`text` などで形を描き、最後に `present` で出す。`background` で塗りつぶす。ふちだけにするなら `no_fill`。

## クラスメソッド

### P5.new

<pre class="fmrb-sig"><code>new(<a href="../FmrbGfx/">FmrbGfx</a> gfx) -&gt; P5</code></pre>

**FmrbGfx を包むだけ**なので、同じ絵に P5 と FmrbGfx の両方から描いてよい。
