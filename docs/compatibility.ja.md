# 動作確認済み機器

実機で動作確認したUSB機器を記載しています。

記載していない機器も動作する可能性がありますが、USB ドライバの機能に制約があるので、機器によって認識しないこともあります。

!!! note "どちらの機種で確認したか"
    以下の結果は **Retro** (narya-board) で取ったものです。USB ホストのドライバは両機種で
    同じものが動くので、片方で動く機器はもう片方でも動くはずですが、Tab5 での再確認は
    していません。

    **Modern** には USB を使わない手もあります。M5Stack Tab5 Keyboard は I2C で本体に
    つながり、ポインタはタッチ画面が使えます。どちらも USB-A 端子を必要としません。

## 接続のヒント

- USBハブ経由で複数同時接続できますが、機器ごとの相性があります（キーボード + マウス + ゲームパッド）
- ロジクールのUSB＆マウス（MK245nBK）を使うのが配線もなくて、おすすめです。
