# Family mruby スタジオ

Family mruby の機械まるごとを、ブラウザの中で動かします。ファームウェア —
FreeRTOS カーネル、Ruby VM、デスクトップ、エディタ、音源 — を WebAssembly に
コンパイルしてあるので、ここで起動するのは実機と同じ OS で、同じ画を
描きます。インストール不要、実機も不要です。

## はじめかた

次の URL を開いて、画面をクリックしてください。クリックが電源スイッチで、
ブラウザに音を許可する操作でもあるので、起動ジングルが鳴ります。

[https://family-mruby.github.io/studio/](/studio/)

初回訪問のときだけ、ページが一度だけ自動的にリロードします (WebAssembly の
スレッドに必要な分離を用意する小さな service worker を入れるためで、
正常な動作です)。

## 動作条件

- 新しめの Chrome か Firefox、キーボードのある PC
- Safari は未確認。スマホ・タブレットは対象外です (この機械はキーボードで
  使うものなので)

## できること

- デスクトップの操作: 左上のメニューからランチャー、エディタ、ファイル
  マネージャなどを開けます。アプリは同時に複数動きます
- エディタで Ruby を書いて動かす。日本語入力も使えます
  (`Ctrl+Space` でかなモード。ローマ字で入力)
- 同梱アプリで遊ぶ。内蔵音源の音も鳴ります
- テーマ (web 既定はネオン調、Classic で実機の配色) と画面サイズ
  (最大 852x480) を選べます。画面を広げると文字が大きくなるのではなく、
  作業空間が広がります

## 制限

- 作ったファイルはブラウザのメモリ上にあり、リロードで消えます。
  残したいものはエディタからコピーして持ち出してください
- 機械の中からネットワークにはまだ出られません
- これは Modern 系の機械です。ハードウェアの楽しさは実機で —
  [はじめかた](choose_hardware.md) へ
