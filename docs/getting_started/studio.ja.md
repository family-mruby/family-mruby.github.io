# Family mruby スタジオ

Family mruby という機械が、そのままブラウザの中で動きます。FreeRTOS のカーネル、Ruby の
VM、デスクトップ、エディタ、音 — ファームウェアをまるごと WebAssembly にコンパイルして
いるので、ここで起動するのは基板で動いているものと同じ OS で、描く絵も同じです。何も
入れる必要はなく、基板も要りません。

## 始め方

次の URL を開いて、画面をクリックしてください。このクリックが電源スイッチです。同時に、
ブラウザに音を出す許可を与える操作でもあるので、起動音が鳴ります。

[https://family-mruby.github.io/studio/](/studio/)

初回だけ、ページが 1 回自分を読み込み直します (WebAssembly のスレッドに必要な分離を
用意する小さな service worker を入れるためです)。異常ではありません。

## 必要なもの

- パソコンの、新しめの Chrome か Firefox。キーボードが要ります
- Safari は未確認です。スマートフォンとタブレットは対象外です (キーボードが要るため)

## できること

- デスクトップを使う。左上のメニューからランチャー、エディタ、ファイルマネージャなどが
  開きます。アプリは並べて動きます
- エディタで Ruby を書いて動かす。日本語入力もできます (`Ctrl+Space` でかなモード、
  ローマ字入力)
- 入っているアプリで遊び、内蔵音源の音を聞く
- テーマ (web の既定はネオン調の独自配色、Classic は実機の配色)、画面の大きさ
  (最大 852x480)、拡大率を選ぶ。画面を大きくすると、絵が大きくなるのではなく広くなります
- 全画面にする。ブラウザが許す場合は `Esc` も機械側が受け取ります。許さない場合、`Esc` は
  アプリに届かず全画面の解除になります

テーマと画面の大きさは起動時に反映されるので、変えるとページを読み込み直します。

## 自分のファイル

書いたものは残ります。`/home` の下 — 保存したプログラム、配色、サービスの一覧 — は
このブラウザの中に、次に来たときも残っています。他のどこにも行きません。今これを読んで
いる機械から出ることはありません。

画面の下のボタンで、まとめて 1 つの `.tar` として取り出せます。そのファイルから戻すことも、
消すこともできます。大事なものは取り出しておいてください。プライベートウィンドウでは何も
残りませんし、長く来ないとブラウザが領域を回収することがあり、同じページを 2 枚開くと
保存するのは最初のタブだけです。取り出したファイルは、ここでも、別のブラウザでも戻せます。

`/home` の外は毎回作り直されます。他の場所に書いたファイル、とりわけ `/tmp` は、次に
読み込み直すと消えています。

## できないこと

- 機械の中からネットワークにはつながりません (今のところ)
- これは Modern 系の機械です。ハードウェアの楽しみはやはり基板の側にあります。
  [機種の選択](choose_hardware.md) を参照してください
