    String¶

    文字列 (UTF-8)

    length と [] の位置は文字数で、バイトではない。バイナリは bytesize・getbyte・ byteslice で扱う。足すたびに新しい文字列ができるので、ループで組み立てるなら <<。 Regexp が無い。

    インスタンスメソッド¶

    String#!¶

    !() -> bool

    真偽を反転する

    文字列はいつも真なので、これは必ず false。

    !"a"  #=> false

    String#*¶

    *(Integer count) -> String

    文字列を指定の回数くり返す

    区切り線や埋め草を作るのに使う。0 を渡すと空になる。

    "-" * 39
"\x00" * 16  # 16 バイトの入れ物

    String#+¶

    +(String other) -> String

    文字列をつなげる

    足すたびに新しい文字列ができるので、ループで組み立てるなら <<。

    a = "foo" + "bar"

    String#<¶

    <(String other) -> bool

    辞書順で前かどうか

    "abc" < "abd"  #=> true

    String#<<¶

    <<(String | Integer string_or_codepoint) -> String

    文字列か文字コードを末尾に足す

    自分を書き換えるので + より速い。数を渡すと文字コードとして足す。

    buf = ""
buf << "a"
buf << 65  # "A"

    String#<=¶

    <=(String other) -> bool

    辞書順で前か同じかどうか

    "abc" <= "abc"  #=> true

    String#<=>¶

    <=>(String other) -> Integer

    辞書順で比べて -1 / 0 / 1 を返す

    並べ替えの比べ物に使う。

    "a" <=> "b"  #=> -1

    String#==¶

    ==(untyped other) -> bool

    等しいかどうか

    中身を比べる。同じ物かどうかではない。

    "abc" == "abc"  #=> true

    String#===¶

    ===(untyped other) -> bool

    case での等しさを判定する

    case s
when "quit" then finish
end

    String#>¶

    >(String other) -> bool

    辞書順で後かどうか

    "b" > "a"  #=> true

    String#>=¶

    >=(String other) -> bool

    辞書順で後か同じかどうか

    "b" >= "b"  #=> true

    String#[]¶

    [](untyped index_or_range) -> (String | nil)

    その位置の文字か部分文字列を返す

    位置は文字数で、バイト数ではない。範囲の外は nil。

    s[0]
s[0, 3]
s[1..2]

    []=(untyped index_or_range, String replacement) -> String

    その位置の文字や部分文字列を置き換える

    長さが変わってよい。1 文字を 3 文字に置き換えてもよい。

    s[0] = "X"

    String#bytes¶

    bytes() -> Array[Integer]

    バイトの並びを配列で返す

    配列を作るので大きい文字列では重い。1 バイトだけなら getbyte。

    "AB".bytes  #=> [65, 66]

    String#bytesize¶

    bytesize() -> Integer

    バイト数を返す (文字数ではない)

    バイナリを扱うならこちら。length は日本語を 1 文字と数えるので食い違う。

    "あ".bytesize  #=> 3
"あ".length    #=> 1

    String#byteslice¶

    byteslice(Integer start, ?Integer length) -> (String | nil)
byteslice(Range range) -> (String | nil)

    バイトの位置と長さで切り出す

    start バイト目から length バイトを、新しい文字列にして返す。 位置も長さもバイトで数える。日本語は 1 文字が 3 バイト (UTF-8) なので、文字で数える []・slice・length・index の値をそのまま渡すと、日本語の入った文字列では位置がずれる。バイトで数える bytesize・getbyte と組み合わせる。

    start が負なら末尾から数える。length が残りより長ければ末尾まで。 start がちょうど末尾 (bytesize) なら ""。それより先か、length が負なら nil (例外は出ない)。続けて文字列のメソッドを呼ぶなら .to_s を挟む。文字の途中で切っても止まらず、欠けた文字のまま返る。

    length を省くと、その 1 バイト (末尾から先は nil)。バイトの範囲 (2..4) でも呼べる。

    s = "あいう"
s.byteslice(3, 3)   #=> "い"
s[1]                #=> "い"
s.byteslice(9, 1)   #=> ""
s.byteslice(10, 1)  #=> nil
rest = s.byteslice(3,
  s.bytesize - 3).to_s

    String#rindex¶

    rindex(String substring, ?Integer offset) -> (Integer | nil)

    後ろから探した位置を返す

    文字の位置で返す (日本語は 1 文字が 1)。見つからなければ nil。 offset (省略すると末尾から) は探し始める文字の位置で、それより後ろは見ない。 文字列だけを受ける (Regexp も Integer も使えない)。

    path.rindex("/")      #=> 8
path.rindex(".", 5)
