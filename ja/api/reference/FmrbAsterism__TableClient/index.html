    FmrbAsterism::TableClient¶

    ゲームホストの卓につなぐ部品

    使い方は ネットワーク のページにあります。

    ゲームホスト (アプリ名 "games") が持つ卓の一覧を探し、卓に入り (join)、見え (view) を取り、卓を出る (leave)。つなぎ直しは中の Link が行い、ホストがネットワークから消えて戻る場合も扱う。

    使い方: on_create で作り、on_update で毎回 update が true の間にゲーム自分の呼び出し (proxy) の答えを集め、その後 update_view を呼ぶ。 on_destroy で close。

    アプリが持つ (呼ばれる) メソッド — 部品がアプリを名前で呼ぶ (ブロックは渡さない)。必須: - table_state(path, state) 卓の状態 (Hash) の put が来た。一覧が覚える値を返す (tables[path]) - table_joined(reply) join に token が返った (token は設定済み。続けて view を取りに行く) - table_refused(why) join が断られた (why はホストの言葉)・答えが無い (why が nil)。table は nil に戻る - table_view(view) 見え (Hash) が届いた無くてよい (持っていれば呼ぶ): - table_link_up(link) つながるたび (購読と on_join / on_leave は設定済み) - table_link_down(link) つなぎそこなった・切れた - table_watch つながっている間の update ごと (状態を読む前) - tables_changed(added) 卓が一覧に増えた (true)・ホストの卓が消えた (false) - table_host_gone 入っている卓のホストが去った - table_host_back そのホストが戻った (見えはまた取る) - table_view_failed 見えに答えが無かった - table_dropped ホストが自分を知らなくなった。無いと leave する - table_ask_view(px, token) 見えの問い合わせを自分で出す (px は卓の async プロキシ)。Future を返す 卓から出る・忘れるとき、入る答えを待っていると、その答えは捨てられる (次の join はすぐ出る)。見えの答えは、エラーでも「ホストはいる」の印になる。

    def on_create
  @tc = FmrbAsterism::TableClient.new(
    self, "othello", tag: "othello")
end
def on_update
  if @tc.update
    @tc.update_view
  end
  100
end
def on_destroy
  @tc.close
end

    定数¶

    名前 型 中身
    HOST_APP String ゲームホストのアプリ名の既定
    CALL_TIMEOUT Float 呼び出しの待ち時間の既定 (秒)

    クラスメソッド¶

    FmrbAsterism::TableClient.new¶

    new(
  untyped owner,
  String kind,
  ?tag: String?,
  ?app: String,
  ?host_app: String,
  ?retry_ms: Integer?,
  ?wifi_wait_ms: Integer?,
  ?settings: FmrbAsterism::Settings?,
  ?blank: untyped
) -> FmrbAsterism::TableClient

    作る (つなぐのは update)

    owner はアプリ (self)。kind は卓の名前の始まり ("othello" なら "<ホスト>/games/othello1" などを探す)。tag: (省略すると kind。ログの頭)、 app: (省略すると "game"。ネットワークでのこのアプリの名前)、 host_app: (省略すると "games"。探すホストのアプリ名)、 retry_ms: (省略すると 3000。nil なら 1 回だけつなぐ)、 wifi_wait_ms: (省略すると ESP32 だけ WiFi を待つ。sim・ブラウザ版は待たない)、 settings: (省略すると FmrbAsterism.settings)、 blank: (省略すると nil。まだ状態が来ていない卓について一覧が持つ値の見本。コピーを入れる。麻雀は {})。アプリが持つメソッド (table_state ほか) はクラスの説明を見る。

    @tc = FmrbAsterism::TableClient.new(
  self, "mahjong", blank: {})

    インスタンスメソッド¶

    FmrbAsterism::TableClient#update¶

    update() -> bool

    毎回呼ぶ (つなぐ・状態・一覧・入る答え)

    つながっている間に、届いた卓の状態を table_state に渡し、卓の一覧を探し、入ろうとした答えを集める。つながっていなければつなぐ (ルータが無いと数秒アプリが止まる。Link#update と同じ)。つながっている間 true。

    if @tc.update
  draw_table
end

    FmrbAsterism::TableClient#update_view¶

    update_view(?Integer now) -> void

    見えを集めて、時が来たら取りに行く

    ゲーム自分の答えを集めたあとに呼ぶ。届いた見えを table_view に渡し、入っていて前の問い合わせが無く時が来ていれば、新しく問い合わせる。卓に入っていなければ何もしない。now (省略すると今の ms) はテスト用。

    @tc.update_view

    FmrbAsterism::TableClient#close¶

    close() -> nil

    閉じる (on_destroy)

    Link を閉じる。卓の leave はしないので、入っていれば先に自分で leave する。

    @tc.close

    show("net: #{@tc.net}")

    FmrbAsterism::TableClient#proxy¶

    proxy(?String path) -> Asterism::Proxy

    卓の相手に呼び出す入口

    proxy は入っている卓、proxy(path) は別の道。呼び出しの待ち時間は call_timeout。待たずに呼ぶなら proxy.async。つながっていないと Asterism::Disconnected、道が無い (卓に入っていない) と ArgumentError。

    f = @tc.proxy.async.play(@tc.token, 3)

    FmrbAsterism::TableClient#join¶

    join(String? path, String name) -> String?

    卓に入る

    呼び出しを出して戻る (答えは update が集め、table_joined か table_refused になる)。すでに入る答えを待っている・path が nil なら何もせず nil。送れなかったら、その失敗の文 (String) を返し、table は nil に戻る。つながっているときに呼ぶ。

    err = @tc.join(path, "Aki")
show(err) if err

    FmrbAsterism::TableClient#ask_view¶

    ask_view() -> void
