    FmrbUI¶

    部品の入れ物

    使い方は UI 部品 のページにあります。

    クラスメソッド¶

    FmrbUI.new¶

    new(
  FmrbApp app,
  ?bg: Integer,
  ?text_size: Integer,
  ?bg_painter: untyped
) -> FmrbUI

    部品箱を作る

    app には自分自身 (FmrbApp) を渡します。描画先と user area の位置をそこから読みます。

    bg: は部品が自分の中を塗る色です (Label の箱、Stepper の値の欄、 Scrollbar の溝)。既定は Window の背景色で、暗い色で塗ったアプリはその色を渡します。省いたときは、アプリをテーマの違う端末へ移すと、着いた側の Window の背景色に変わります (渡した色はそのまま)。

    bg_painter: は部品を消したあとの地を描く相手です。渡さなければ跡は bg: の色で塗られます (地が一色ならこれで正しい)。地が絵の場合 (壁紙・枠線・角の丸み) は、paint_bg_rect(gfx, x, y, w, h) を持つオブジェクト (ふつうは self) を渡すと、その矩形を自分で描けます。実装は描くだけ。present しない、確保しない、文字サイズやフォントを変えたら戻す。名前は固定です。

    @ui = FmrbUI.new(self)                    # Window の背景色
@ui = FmrbUI.new(self, bg: COLOR_BG)      # 自前の背景色
@ui = FmrbUI.new(self, bg_painter: self)  # 地は自分で描く

def paint_bg_rect(gfx, x, y, w, h)
  gfx.fill_rect(x, y, w, h, 0x01)
end

    インスタンスメソッド¶

    FmrbUI#label¶

    label(
  Symbol id,
  Integer x,
  Integer y,
  Integer w,
  Integer h,
  String text,
  ?align: Symbol,
  ?text_size: Integer
) -> FmrbUI::Label

    文字を置く

    align: で寄せ方を選べます (:left / :center / :right、既定は :left)。 text_size: でこの部品だけ文字を大きくできます (1-4)。見出しに使います。

    @ui.label(:l_size, 4, 148, 60, 10,
          "大きさ")

    FmrbUI#button¶

    button(
  Symbol id,
  Integer x,
  Integer y,
  Integer w,
  Integer h,
  String text,
  ?text_size: Integer,
  ?accent: Integer
) -> FmrbUI::Button

    押しボタンを置く

    押している間だけ反転し、離したときに handle が id を返します。部品の外で離したときは何も起きません。

    accent: に色 (RGB332) を渡すと、テーマのボタン色の代わりにその色で塗ります。色そのものが意味を持つ数少ない場合だけに使います (確認ダイアログの Yes、再生/停止など)。Toggle では入のときの色です。

    @ui.button(:start, 4, 20, 60, 16,
           "Start")

    FmrbUI#toggle¶

    toggle(
  Symbol id,
  Integer x,
  Integer y,
  Integer w,
  Integer h,
  String text,
  ?group: Symbol,
  ?on: bool,
  ?on_text: String,
  ?text_size: Integer,
  ?accent: Integer
) -> FmrbUI::Toggle

    入切の切替を置く

    group: に同じ名前を付けた切替どうしは、一つだけが入になります (ラジオボタン)。on: true で最初から入、on_text: を渡すと入のときの文字を変えられます。

    @ui.toggle(:maru, 0, 0, 50, 16, "円", group: :motif, on: true)
@ui.toggle(:hishi, 58, 0, 50, 16, "菱", group: :motif)
@ui.toggle(:invert, 0, 20, 108, 12, "反転 切", on_text: "反転 入")

    FmrbUI#stepper¶

    stepper(
  Symbol id,
  Integer x,
  Integer y,
  Integer w,
  Integer h,
  Integer value,
  Integer min,
  Integer max,
  ?Integer step,
  ?text_size: Integer
) -> FmrbUI::Stepper

    数を増減する部品を置く

    「< 値 >」の形で、左右どちらを押しても handle が id を返します。 min / max で止まり、端で押したときは id を返しません。最後に step (増減の幅、既定は 1) を渡せます。

    @size = @ui.stepper(:size, 0, 0, 108, 14, 70, 30, 100, 10)
@size.suffix = "%"   # 表示を "70%" にする

    FmrbUI#enum¶

    enum(
  Symbol id,
  Integer x,
  Integer y,
  Integer w,
  Integer h,
  Array[String] options,
  ?index: Integer,
  ?text_size: Integer
) -> FmrbUI::Enum

    選択肢を左右で選ぶ部品を置く

    「< 選択肢 >」の形で、options の中身を左右で送ります。value は選ばれた添字、option_text はその文字列です。端では止まり、巡回しません。文字を作り直さないので Stepper より軽い部品です。 index: (省略すると 0) は最初に選ばれている添字、text_size: はこの部品だけの文字の大きさです。options は読むだけで書き換えません。

    THEMES = ["light", "dark", "classic"]
@ui.enum(:theme, 0, 0, 90, 14, THEMES, index: 1)
# ...
when :theme then apply_theme(@ui.option_text(:theme))

    FmrbUI#scrollbar¶

    scrollbar(
  Symbol id,
  Integer x,
  Integer y,
  Integer w,
  Integer h,
  Integer total,
  Integer visible,
  ?Integer scroll
) -> FmrbUI::Scrollbar

    縦のスクロールバーを置く

    x, y, w, h はバーそのものの矩形で、動かす一覧のものではありません (幅は 10 が標準)。total (全部の数)・visible (見える数)・scroll (今の位置、省略すると 0) の 3 つだけでつまみの大きさと位置が決まります。 位置を持つのはアプリです。キーなどで動かしたら set_value、件数が変わったら set_range で入れ、バーを押されたら value で読み戻します。ホイールには応えません (wheel_rows で自分で受ける)。

    押した瞬間に handle が id を返し (離したときではない)、押し続けても返るのは最初の 1 回だけです。1 回で 1 つ動き、端で押したときは返りません。押している間の向きは direction で読み、繰り返しはアプリがします。全部が見えている (total が visible 以下の) 間は何も描かず、 クリックも後ろの一覧へ通ります。作るのは on_create が前提です (作る呼び出しは確保が起きる。大きさが変わるアプリは on_resize で作り直す)。

    @ui.scrollbar(:sb, w - 10, y, 10, h,
              0, rows, 0)
# ...
@ui.set_range(:sb, @files.size, rows)
@ui.set_value(:sb, @scroll)

    FmrbUI#option_text¶

    option_text(Symbol id) -> String?

    選ばれている文字

    Enum が今見せている文字列です。添字は value で読みます。

    name = @ui.option_text(:mode)

    FmrbUI#text_field¶

    text_field(
  Symbol id,
  Integer x,
  Integer y,
  Integer w,
  Integer h,
  ?String text,
  ?max: Integer,
  ?text_size: Integer
) -> FmrbUI::TextField

    1 行の文字入力欄を置く

    クリックで焦点が移り、焦点のある欄にキーが入ります。Enter で handle が id を返し (確定)、Esc で焦点が外れます。文字数は max まで。カーソルは点滅しません (点滅は毎フレーム描くことになるため)。矢印キーによる欄内の移動はありません。追加と後退だけです。

    @ui.text_field(:name, 40, 100, 120, 10, "song", max: 24)
# ...
when :name then save_as(@ui.field_text(:name))

    焦点を当てる

    nil を渡すと焦点を外します。文字入力欄以外を渡した場合も外れます。

    @ui.focus(:name)
@ui.focus(nil)

    焦点のある部品の名前

    return if @ui.focused == :name

    FmrbUI#handle¶

    handle(Hash[Symbol, untyped] ev) -> Symbol?

    イベントを渡す

    操作が決まった部品の id を返します。決まっていなければ nil です。押し下げでは押した見た目にするだけで nil を返し、同じ部品の上で離したときに id を返します。mouse_move は何もせず nil です。

    case @ui.handle(ev)
when :start then start_game
end

    FmrbUI#flush¶

    flush() -> bool

    変わった部品だけ描く

    描くものがあれば最後に present を 1 回呼んで true、何も変わっていなければ何もせず false を返します。自分の絵を描いたあとに呼べば present は 1 回で済みます。

    draw_picture
@gfx.present unless @ui.flush

    FmrbUI#set_enabled¶

    set_enabled(Symbol id, bool flag) -> void

    部品を使える/使えないにする

    @ui.set_enabled(:export, false)

    FmrbUI#set_visible¶

    set_visible(Symbol id, bool flag) -> void

    部品を出す/隠す

    隠した部品のあった場所は背景色で塗り直されます。

    @ui.set_visible(:inst, false)

    FmrbUI#set_range¶

    set_range(Symbol id, Integer min, Integer max) -> void

    範囲を入れ直す

    部品によって 2 つの数の意味が違います。Stepper (と Enum) は (min, max)、Scrollbar は (total, visible)。値は新しい範囲の中へ引き戻されます。同じ範囲なら何もせず、id が無いときも何も起きません (常に nil)。ほかの部品では何もしません。

    @ui.set_range(:track, 1, total)    # Stepper
@ui.set_range(:sb, @files.size, 8) # Scrollbar

    FmrbUI#direction¶

    direction(Symbol id) -> Integer

    つまみを押している向き

    上へ押している間は -1、下へは 1、押していなければ 0 (id が無いときも 0)。 handle が id を返したあとに読み、押している間の繰り返しに使います。

    if @ui.handle(ev) == :sb
  d = @ui.direction(:sb)
  @scroll_hold = d
end

    FmrbUI#bg¶

    bg() -> Integer

    部品の地の色

    c = @ui.bg

    FmrbUI#bg=¶

    bg=(Integer c) -> void

    部品の地の色を変える

    あとから作る部品と、隠した部品の跡を塗る色が変わり、 すでにある部品の中の色も、作るときにここから写した色のものは新しい色になって、次の flush で描き直されます。部品の bg= で自分の色を渡した部品はその色のままです。渡した色は自前の色として扱われ、アプリを別の端末へ移してもテーマの色には戻りません。部品の外の地 (アプリが塗る所) は、アプリが塗り直します。

    @ui.bg = @bg_col
@ui.flush
