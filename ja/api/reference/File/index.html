    File¶

    ファイルの読み書き (File)

    使い方は ファイル・I/O のページにあります。

    継承元: IO

    IO の子クラスで、write・puts・print・flush・close・closed? は IO のもの。実装は Family mruby の gem picoruby-fmrb-filesystem (lib/gems/picoruby-fmrb-filesystem/: mrblib/file.rb、ports/esp32/fmrb_filesystem.c) と picoruby-fmrb-io。 CRuby の File にあって無いもの: gets・each_line・readlines・seek・eof?・File.read・File.write・File.binread・ File.foreach・File.stat・File.mtime ほか。読むのは read、全体を一度に書く・読むなら FmrbFile。 失敗は RuntimeError (Errno::ENOENT などは無く、ファイルが無い・書けない・数が多すぎる、はメッセージだけで区別する)。書いてよい場所は /home と /tmp (/tmp は RAM の上の小さな一時置き場)。

    定数¶

    名前 型 中身
    SEPARATOR String パスの区切り

    クラスメソッド¶

    File.new¶

    new(String path, ?String mode, ?Integer perm) -> File

    ファイルを開く (new)

    mode は "r" (省略時・読む)・"w" (空にして書く。無ければ作る)・"a" (末尾に足す。無ければ作る) と、"r+" (読み書き。無いと失敗)・"w+" (空にして読み書き)・"a+" (読めて、書くと必ず末尾に足す。無ければ作る)。b は付けてもよく ("rb+" は "r+" と同じ)、 ほかの文字で始まる mode は読み取り専用として開く (エラーにならない)。 "w"・"a" で開いたものの read と、"r" で開いたものの write・puts・print は IOError。perm は受け取るだけで使わない。

    開けないと RuntimeError ("failed to open file: パス")。理由 (無い・場所が無い・開いている数が上限) は区別できない。開いたままにできるのは、ESP32 では全アプリで 10 個。開いた File は使い終えたら close する (File.open のブロックなら自動)。

    f = File.new("/home/a.txt", "w")
f.write("hi")
f.close

    File.join¶

    join(*String | Array[untyped] names) -> String

    パスを組み立てる

    部品の間に "/" を 1 つだけ入れてつなぐ (重なった "/" は 1 つに)。部品は String か、 String の配列 (入れ子も可)。ほかは TypeError。引数が無いと ""。

    File.join("/home", "a.txt")   #=> "/home/a.txt"

    File.basename¶

    basename(String path, ?String suffix) -> String

    パスの最後の名前

    末尾の "/" は無視する。suffix (省略すると何も取らない) が名前の終わりに一致すれば取り除く (文字列そのままの一致だけ。CRuby の ".*" は使えない)。"/" は "/"。

    File.basename("/home/a.txt")          #=> "a.txt"
File.basename("/home/a.txt", ".txt")  #=> "a"

    File.dirname¶

    dirname(String path, ?Integer level) -> String

    パスの親のディレクトリ

    File.dirname("/home/a.txt")   #=> "/home"

    File.extname¶

    extname(String filename) -> String

    拡張子 (ドットを含む)

    File.extname("a.txt")   #=> ".txt"

    File.expand_path¶

    expand_path(String path, ?String default_dir) -> String

    絶対パスにする

    "." と ".." をたどり、重なった "/" をまとめる。 相対パスの基準は default_dir (省略すると ".") をアプリの作業ディレクトリ (Dir.getwd) に付けたもの。 "~" で始まるパスは環境変数 HOME に置き換わり、HOME が無いと ArgumentError。 "~名前" の形は ArgumentError。ファイルがあるかは見ない。

    File.expand_path("/home/../tmp/a")   #=> "/tmp/a"

    File.exists?¶

    exists?(String path) -> bool

    ファイルかディレクトリがあるか (exists? も同じ)

    ディレクトリでも true。無い・調べられないときは false (例外は出ない)。 exists? は同じ働きの別名。

    File.file?¶

    file?(String path) -> bool

    普通のファイルか

    ディレクトリや、無いパスは false。

    File.file?("/home/a.txt")

    File.directory?¶

    directory?(String path) -> bool

    ディレクトリか

    無いパスは false。"/"・"/mnt" は true。

    File.directory?("/tmp")

    File.size¶

    size(String path) -> Integer

    ファイルの大きさ (バイト)

    無いと nil でなく RuntimeError ("stat failed for パス")。先に File.exist? で調べる。 (nil を返す FmrbFile.size もある。)

    n = File.size("/home/a.txt")

    File.delete¶

    delete(String path) -> Integer

    ファイルを消す

    パスは 1 つだけ (CRuby のように複数は渡せない)。消せたら 1 を返し、 消せないと RuntimeError ("cannot delete パス")。無い・ディレクトリ・開いたままのファイルは消せない (ディレクトリは Dir.delete)。unlink は同じ働きの別名。

    File.delete("/home/old.txt") if File.exist?("/home/old.txt")

    File.unlink¶

    unlink(String path) -> Integer

    ファイルを消す (delete の別名)

    File.unlink("/home/old.txt")

    File.rename¶

    rename(String old_path, String new_path) -> Integer

    名前を変える・移す

    成功すると 0。失敗すると RuntimeError ("cannot rename 元 to 先")。先に同じ名前のファイルがあるときの動きは、実装の rename(3) まかせ (確かめていない。先に File.delete すると確実)。

    File.rename("/home/a.tmp", "/home/a.txt")

    File.open¶

    open(String path, ?String mode) -> File
open(String path, ?String mode) { (File file) -> untyped } -> untyped

    ファイルを開く

    ブロックを渡した形が安全 (抜けるときに閉じ、ブロックの値を返す)。 mode は "r" "w" "a" (省略すると "r"。細かい形は File.new)。無いファイルを読もうとすると RuntimeError。File.binread は無い ので、読むのは read。

    File.open("/home/a.txt", "r") do |f|
  body = f.read
end

    File.exist?¶

    exist?(String path) -> bool

    ファイルがあるかどうか

    return unless File.exist?(path)

    インスタンスメソッド¶

    File#path¶

    path() -> String

    開いたファイルのパス

    f.path

    File#path=¶

    path=(String value) -> String

    パスを置き換える (記録だけ)

    path が返す値を変えるだけで、ファイルは動かない。

    f.path = "/home/b.txt"

    File#read¶

    read(?Integer length) -> String

    中身を読む (長さを渡せばその分だけ)

    引数なしなら残り全部が文字列で返る。 大きいファイルは丸ごとメモリに載るので、少しずつ処理するなら長さ (バイト) を渡して回す。終わりまで読んだ後は nil でなく "" が返る。

    gets (1 行読む) は無い (呼ぶと NoMethodError)。行で分けるなら、読んだ文字列を split("\n") する。

    body = f.read
head = f.read(16)
body.split("\n").each do |line|
  handle(line)
end

    File#write¶

    write(String str) -> Integer

    書き込む

    書けたバイト数が返る。

    f.write("hello\n")

    File#close¶

    close() -> void

    閉じる

    ブロック付きの open なら要らない。

    f.close
