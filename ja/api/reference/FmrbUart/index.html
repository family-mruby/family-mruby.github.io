    FmrbUart¶

    アプリの UART の境界の関数

    使い方は ハードウェア制御 のページにあります。

    UART クラスの下の層。番号 (unit) で呼び、開いたアプリだけが使える (ほかのアプリの番号は RuntimeError)。Ruby のアプリはふつう UART を使う。ほかの言語 (C・Lua・ MicroPython・wasm) はこの形がそのまま見える。読む関数は待たない。unit_mask でその端末が開ける番号を先に確かめられる (ブラウザ版・ネイティブ版は 0)。

    r = FmrbUart.open(2, 47, 48, 115200,
                  8, 1, 0, 4096)
FmrbUart.write(2, "hi\n") if r == 0

    クラスメソッド¶

    FmrbUart.open¶

    open(
  Integer unit,
  Integer txd_pin,
  Integer rxd_pin,
  Integer baudrate,
  Integer data_bits,
  Integer stop_bits,
  Integer parity,
  Integer rx_buffer_size
) -> Integer

    UART を開く (0 で成功、ほかは理由の番号)

    引数は全部要る (parity は 0 無し・1 偶数・2 奇数、rx_buffer_size は 16〜16384 の 2 のべき乗)。ピンの片方は -1 でよい。答えの番号 (下位 8 ビット): 1 番号が無い・2 ピンが無い・ 3 ピンが両方 -1・4 TX と RX が同じ・5 速さ・6 形式・7 箱の大きさ (ここまで引数の誤り)、 8 本体の番号・9 ほかのアプリが使用中・10 MIDI が使用中・11 システムのピン・12 入力だけの線を TX に・13 ピンが使用中・14 開けなかった・15 この環境に無い。ピンについての答えは次のバイトにどちらか (1 TX、2 RX) が入る (r >> 8)。

    r = FmrbUart.open(2, 47, 48, 9600,
                  8, 1, 0, 4096)

    FmrbUart.close¶

    close(Integer unit) -> bool

    閉じてピンを返す (閉じたら true)

    自分が開いていない番号なら false。

    FmrbUart.close(2)

    FmrbUart.read¶

    read(Integer unit, Integer max) -> bin

    届いた分を max バイトまで読む (待たない)

    無ければ空の文字列。C などで呼ぶ側の箱が答えより小さいと、何も取らずに全体の長さを返し、次にその長さの箱で呼ぶと同じバイトを取る。

    s = FmrbUart.read(2, 64)

    FmrbUart.read_line¶

    read_line(Integer unit) -> bin?

    "\n" まで 1 行読む (無ければ nil)

    "\n" を含めて返す。まだ届いていなければ nil で、何も取らない。

    line = FmrbUart.read_line(2)

    FmrbUart.write¶

    write(Integer unit, bin data) -> Integer

    送る (4096 バイトまで、待つ)

    送ったバイト数を返す。4096 バイトより長いと ArgumentError (UART#write は分けて送る)。

    FmrbUart.write(2, "AT\r\n")

    bytes_available(Integer unit) -> Integer

    n = FmrbUart.bytes_available(2)

    unget(Integer unit, Integer byte) -> bool

    FmrbUart.unget(2, 0x41)

    flush(Integer unit) -> bool

    送った物が出きるまで待つ (1 秒まで)

    出きったら true、待ちきれなければ false。

    ブレークを ms ミリ秒送る

    0〜10000。その間待つ。Linux sim では何もしない。

    速さを変える (実際の速さを返す)

    dropped(Integer unit) -> Integer

    FmrbUart.dropped(2)

    FmrbUart.unit_mask¶

    unit_mask() -> Integer

    アプリが開ける番号 (1 ビットずつ)

    ビット n が立っていれば UARTn を開ける。ブラウザ版・ネイティブ版は 0。

    m = FmrbUart.unit_mask
ok = (m >> 2) & 1 == 1   # UART2
