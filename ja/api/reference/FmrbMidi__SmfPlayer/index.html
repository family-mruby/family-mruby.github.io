    FmrbMidi::SmfPlayer¶

    曲のファイル (SMF) を鳴らす係

    使い方は MIDI のページにあります。

    tick を毎回呼んで進める。

    定数¶

    名前 型 中身
    LOOKAHEAD_US Integer 待ち行列に先に入れておく長さ (µs)

    クラスメソッド¶

    FmrbMidi::SmfPlayer.new¶

    new(MIDI::Device device) -> SmfPlayer

    曲を鳴らす係を作る

    @smf = FmrbMidi::SmfPlayer.new(@midi)

    インスタンスメソッド¶

    FmrbMidi::SmfPlayer#load¶

    load(String path) -> bool

    曲のファイルを読み込む

    読めなければ false。理由は error に入る。読む前に鳴っていた曲は止まる。形式 2 の SMF は読めない。読み込むと tempo_scale・transpose・channel_mask・ ignore_program_change は初期値に戻るので、読んだあとで設定する。

    unless @smf.load("/home/a.mid")
  puts @smf.error
end

    FmrbMidi::SmfPlayer#load_string¶

    load_string(String data, ?String path) -> bool

    曲のバイト列を読み込む

    load の、メモリにあるバイト列を渡す版。読めなければ false、理由は error。path (省略すると nil) は path メソッドが返す名前になるだけで、ファイルは読まない。load と同じく設定は初期値に戻る。

    @smf.load_string(data, "from net")

    FmrbMidi::SmfPlayer#loaded?¶

    loaded?() -> bool

    読み込んだかどうか

    return unless @smf.loaded?

    FmrbMidi::SmfPlayer#start¶

    start() -> bool

    曲を鳴らし始める

    頭から鳴らし直す。途中から続けるなら resume。 すぐ戻る (鳴り終わるのは待たない)。読んでいなければ false。音が出るのは tick を回してからなので、on_update で呼び続ける。

    @smf.start

    FmrbMidi::SmfPlayer#stop¶

    stop() -> void

    曲を止める

    このプレーヤーが待ち行列に入れた分を捨て、鳴っている音を止める。 1 つのアプリでプレーヤーを 2 つ鳴らしていても、もう片方の分は残る (pause・device= も同じ)。

    @smf.stop

    FmrbMidi::SmfPlayer#pause¶

    pause() -> bool

    曲をいったん止める

    鳴っていなければ (止まっている・もう止めた) false。

    @smf.pause

    FmrbMidi::SmfPlayer#resume¶

    resume() -> bool

    止めた曲の続きを鳴らす

    止める前に待ち行列へ入れてあった分 (最大 0.3 秒) は捨てられるので、その分だけ先から続く。止めていなければ false。

    @smf.resume

    FmrbMidi::SmfPlayer#playing?¶

    playing?() -> bool

    鳴っている最中かどうか

    曲を最後まで読み、このプレーヤーが予約した音が全部鳴ったら false になる。ほかのプレーヤー (同じアプリでも別のアプリでも) が鳴らしている間も、自分の分が終われば false。

    draw_bar if @smf.playing?

    FmrbMidi::SmfPlayer#finished?¶

    finished?() -> bool

    最後まで鳴り終わったか

    読み込んだだけで鳴らしていない曲や、stop した曲でも true。「鳴っていない」の意味なので、終わりを見るなら playing? が false に変わるのを見る。

    @smf.start if @smf.finished?

    FmrbMidi::SmfPlayer#tick¶

    tick() -> Integer?

    曲を進める。毎回呼ぶ

    呼ばないと音が進まない。毎フレームの決まった場所で 1 回呼ぶ。戻りは、次に呼ぶまでの待ち時間 (ms)。何かが今すぐ要るなら 0、鳴っていない・終わったなら nil。曲の最後まで読み終えたあとも、待ち行列の音が鳴り切るまでは 20 が返り、そのあと nil になる。

    def on_update
  @smf.tick
end

    FmrbMidi::SmfPlayer#next_delay¶

    next_delay(Integer default_ms) -> Integer

    曲を進めて待ち時間を返す

    tick を呼び、その戻りと渡した default_ms の短いほうを返す。 on_update の戻り値にする。鳴っていなければ default_ms。

    def on_update
  @smf.next_delay(300)
end

    FmrbMidi::SmfPlayer#position_ms¶

    position_ms() -> Integer

    今どこまで鳴ったか (千分の一秒)

    sec = @smf.position_ms / 1000

    FmrbMidi::SmfPlayer#channel_usage¶

    channel_usage() -> Hash

    使っているチャンネルの様子

    使われている channel だけが入る。中身は [音符の数, 高さの合計]。読み込んでいなければ空。

    @smf.channel_usage.each do |ch, a|
  puts ch.to_s + ": " + a[0].to_s
end

    FmrbMidi::SmfPlayer#device=¶

    device=(MIDI::Device value) -> void

    鳴らす先のデバイスを切り替える

    鳴らしている最中でも変えられる。古いデバイスで鳴っていた音は止まり、待ち行列に入れてあった分 (最大 0.3 秒) は捨てられる。内蔵音源と外の音源 (FmrbMidi.sam2695_device) の切り替えに使う。

    @smf.device = @serial

    FmrbMidi::SmfPlayer#lookahead_us¶

    lookahead_us() -> Integer

    先に待ち行列へ入れる長さ (µs)

    内蔵音源やシリアルのデバイスでは既定で 300000 (LOOKAHEAD_US)。時間つきで受けられないデバイスでは 0。

    n = @smf.lookahead_us

    FmrbMidi::SmfPlayer#lookahead_us=¶

    lookahead_us=(Integer us) -> void

    先に待ち行列へ入れる長さを変える

    単位は µs。0 にすると送るのをアプリのタスクに戻す (描画などで遅れたぶんだけ音がずれる。比べるときに使う)。0 より大きくしても、デバイスが時間つきで受けられない (スケジューラが無い) ときは 0 のまま。 変えると待ち行列を捨てるので、鳴らす前に変える。

    @smf.lookahead_us = 0

    FmrbMidi::SmfPlayer#transpose¶

    transpose() -> Integer

    全部の音に足す半音の数

    0 が元のまま。channel 9 (ドラム) は動かさない。0〜127 を出る音も元の高さのまま。鳴らしている途中でも変えられ、次の音から効く (鳴っている音は始めた高さで止める)。load で 0 に戻る。

    @smf.transpose = 2

    FmrbMidi::SmfPlayer#transpose=¶

    transpose=(Integer semitones) -> void

    半音の数を変える

    transpose を見る。

    @smf.transpose = -12

    FmrbMidi::SmfPlayer#channel_mask¶

    channel_mask() -> Integer?

    鳴らす channel の指定

    nil なら全部。数なら、ビット n が channel n (0〜15) で、0 の channel の音・つまみ・楽器の指定はすべて飛ばす。load で nil に戻る。

    m = @smf.channel_mask

    channel_mask=(Integer? mask) -> void

    鳴らす channel を指定する

    channel_mask を見る。nil で全部。

    @smf.channel_mask = 0b101

    FmrbMidi::SmfPlayer#ignore_program_change¶

    ignore_program_change() -> bool

    曲の楽器の指定を使わないか

    true なら、曲の中の楽器の指定 (Program Change) を送らない。アプリで選んだ楽器を、曲が途中で上書きしないようにする。楽器を持つ外の音源にだけ効く (内蔵音源はどちらでも落とす)。load で false に戻る。

    @smf.ignore_program_change = true

    FmrbMidi::SmfPlayer#ignore_program_change=¶

    ignore_program_change=(bool value) -> void

    曲の楽器の指定を使わないようにする

    ignore_program_change を見る。

    @smf.ignore_program_change = false

    FmrbMidi::SmfPlayer#timing_stats¶

    timing_stats() -> String

    送り具合の一行の報告

    ログに出す文字列。何も送っていないうちは "no events yet"。スケジューラがあれば events・fired・avg_late・max_late・stalls・under・ q (待ち行列の深さ) などが並ぶ。

    Log.info(@smf.timing_stats)
