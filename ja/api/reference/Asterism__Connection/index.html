    Asterism::Connection¶

    ネットワーク上のアプリ 1 つ分のつながり

    使い方は ネットワーク のページにあります。

    link.conn で得る。

    インスタンスメソッド¶

    Asterism::Connection#expose¶

    expose(
  String name,
  untyped obj,
  methods: Array[untyped] | Hash[untyped, untyped],
  ?caller: (Symbol | String)?,
  ?doc: String?
) -> String

    オブジェクトを公開する

    name はオブジェクトの名前で、ほかの端末からは "<この端末>/<アプリ>/" で呼ばれる。 methods: はキーワードで渡す: 呼んでよいメソッドの名前と引数の数の Hash ({ post: 1 }。数は呼ばれる前に確かめる、-1 は何個でも) か、名前の Array。並べたメソッドだけが呼べる。obj にそのメソッドが無いと ArgumentError。公開したメソッドは update の中で呼ばれる。メソッドが例外を出すと、呼んだ側に RemoteError で届く。 caller: (省略すると渡さない) に :from のようなキーワード名を渡すと、呼ぶたびに呼んだ端末の名前がそのキーワードで公開メソッドに渡る。 doc: (省略すると無し) はオブジェクトの説明 (2048 バイトまで)。戻り値は公開した道 ("node/app/name")。link_up の中で呼ぶ。

    def link_up(link)
  link.conn.expose("board", self,
    methods: { post: 1 })
end

def post(text)
  @lines << text
  @lines.size
end

    Asterism::Connection#[]¶

    [](
  String path,
  ?timeout: (Integer | Float)?,
  ?timeout_ms: Integer?
) -> Asterism::Proxy

    ほかの端末のオブジェクトを受け取る

    path は "<端末>/<アプリ>/<オブジェクト>"。受け取っただけでは何も送らない。そのメソッドを呼ぶと相手で動き、答えを待つ (既定 2 秒。 timeout: で秒を変えられる。ミリ秒なら timeout_ms:)。待つ間も、こちらに来た呼び出しには答える。待たずに呼ぶなら async。失敗: 相手が例外を出した・公開していない・引数の数が違うと Asterism::RemoteError、時間切れは Asterism::TimeoutError、つながっていないと Asterism::Disconnected。どれも Asterism::Error。

    b = @link.conn[
  "fmruby-1/talk_board/board"]
begin
  n = b.post("hello")
rescue ::Asterism::Error => e
  show(e.message)
end

    Asterism::Connection#each¶

    each(?String pattern) -> Array[Asterism::Proxy]
each(?String pattern) { (Asterism::Proxy proxy) -> untyped } -> Integer

    公開されているオブジェクトを探す

    pattern の * は 1 区切り、** は何区切りでも (省略すると全部)。この端末の物も入る。答えはオブジェクトの Array (受け取り方は conn[path] と同じ)。ブロックを渡すと 1 つずつ渡し、数を返す。ネットワークに問い合わせないので、毎回呼んでよい。

    list = @link.conn.each(
  "*/talk_board/board")
@board = list[0]

    path() -> String

    この端末/アプリの道

    me = @link.conn.path

    Asterism::Connection#publish¶

    publish(
  String | Symbol name,
  ?type: (Symbol | Integer | String)?,
  ?unit: String?,
  ?desc: String?,
  ?ts: bool,
  ?encoding: String?,
  ?shared: (Symbol | String)?
) -> Asterism::Topic

    トピックを出す (値を流せるように宣言する)

    name は "said" や "game/score" (区切りは /)。ほかの端末からは "<この端末>/<アプリ>/" で受ける。返った Topic の put で値を流す。キーワード (type:・unit:・desc:・ts:) は省ける。残らない (後から受け始めた側には前の値は届かない)。つながっていないと Asterism::Disconnected。link_up の中で呼ぶ。

    def link_up(link)
  @said = link.conn.publish("said")
end
# ...
@said.put({ "text" => "hi" })

    Asterism::Connection#subscribe¶

    subscribe(
  String path,
  ?depth: Integer?
) { (untyped value, Asterism::SampleInfo info) -> untyped } -> Asterism::Subscription

    トピックを受ける (ブロックで)

    path は "<端末>/<アプリ>/<トピック>"。* は 1 区切り、** は何区切りでも。値が来るたびに、update の中でブロックが |値, info| で呼ばれる (info は Asterism::SampleInfo)。自分で put した値は自分には届かない。depth: で溜める数を変えられる。止めるには返った Subscription の close。link_up の中で呼ぶ。

    def link_up(link)
  link.conn.subscribe(
    "*/talk_board/said") do |v, info|
    got(v, info.from)
  end
end

    Asterism::Connection#status¶

    status(?Hash status, **untyped fields) -> Hash?

    このアプリの状態を出す

    Hash を渡すと全部を入れ替え、キーワードで渡すとその項目だけ変わる (nil で消える)。変わったときだけ流れる。1 KB まで。引数なしなら今の状態を返す (無ければ nil)。status(lines: 3) のようにキーワードで渡すと、その項目だけが変わる。

    @link.conn.status(
  { "lines" => @lines.size })

    Asterism::Connection#status_of¶

    status_of(
  String node,
  String app,
  ?timeout: (Integer | Float)?,
  ?timeout_ms: Integer?
) -> Hash?

    ほかのアプリの状態を読む

    答えを待つ (既定 2 秒。timeout: は秒、timeout_ms: はミリ秒)。つながっていないと Asterism::Disconnected。

    st = @link.conn.status_of(
  "fmruby-1", "talk_board")

    Asterism::Connection#on_join¶

    on_join() { (String node) -> untyped } -> Asterism::Connection

    端末が来たときに呼ぶブロック

    ブロックは |端末の名前| で、update の中で呼ばれる。link_up の中で渡す (つなぎ直すと消えるため)。

    link.conn.on_join { |n| joined(n) }

    Asterism::Connection#on_leave¶

    on_leave() { (String node) -> untyped } -> Asterism::Connection

    端末が去ったときに呼ぶブロック

    切れたときは、知っていた端末が全部去る。

    link.conn.on_leave { |n| left(n) }

    Asterism::Connection#current_call¶

    current_call() -> Asterism::CurrentCall?

    今答えている呼び出し (だれから)

    公開したメソッドの中で、呼んだ端末の名前を知るのに使う。

    def post(text)
  who = @link.conn.current_call.from
  add("#{who}: #{text}")
end

    Asterism::Connection#run_id¶

    run_id() -> Integer

    今の接続の番号

    接続するたびに変わる。トピックの値に付いて、受ける側が「送り手がつなぎ直した」と気づくのに使う (SampleInfo#restarted?)。

    id = @link.conn.run_id

    Asterism::Connection#connected?¶

    connected?() -> bool

    つながっているか

    つなぎ直しの途中 (reconnecting?) も true。セッションが閉じていると気づいたときは、その場で「切れた」ことにして false を返す。

    return unless conn.connected?

    Asterism::Connection#reconnecting?¶

    reconnecting?() -> bool

    切れたあと自動でつなぎ直している最中か

    true の間は connected? も true。ほかの端末は一度 leave し、戻ると join し直す。呼び出しは Disconnected か時間切れ、put は誰にも届かない。戻ると、公開したオブジェクト・トピック・購読は元のまま使える。

    if conn.reconnecting?
  show("reconnecting")
end

    Asterism::Connection#lost_reason¶

    lost_reason() -> String?

    つながっていない理由

    why = @link.conn.lost_reason

    Asterism::Connection#close¶

    close() -> nil

    つながりを閉じる

    公開・トピック・購読もいっしょに終わり、on_join などのブロックも忘れる。何度呼んでも構わない。閉じたものはもう開かない (Asterism.connect で作り直す)。Link を使うなら Link#close でよい。戻り値は nil。

    conn.close

    Asterism::Connection#poll¶

    poll() -> bool

    毎回呼ぶ (答える・受ける・知らせる)

    届いた呼び出しに答え、on_join / on_leave のブロックと subscribe のブロックを呼ぶ。つなぎ直しの待ちの中からは呼ばれない。閉じたら false。 Link を使うなら Link#update が呼ぶので、自分では呼ばない。 Asterism.poll_all はプログラムの全部の接続を呼ぶ。

    conn = Asterism.connect(r, app: "x")
conn.poll

    Asterism::Connection#session¶

    session() -> untyped

    Zenoh のセッション

    ROS 2 の Node (Asterism::ROS::Node.new(conn.session, ...)) や put・subscribe を直接使うとき用。セッションは接続のもので、そこから close しても何も起きない (1 回だけ警告)。閉じるのは Connection#close。つながっていないと Asterism::Disconnected。

    s = @link.conn.session
node = Asterism::ROS::Node.new(s, "n")

    Asterism::Connection#published¶

    published() -> Array[String]

    出しているトピックの名前

    list = @link.conn.published

    Asterism::Connection#unpublish¶

    unpublish(
  Asterism::Topic | String | Symbol topic,
  ?shared: (Symbol | String)?
) -> bool

    トピックをやめる

    Topic か、publish に渡した名前 (共有なら同じ shared: も) を渡す。宣言が消える。やめたら true、無いものは false。同じ名前でまた publish すると番号は続きから。

    @link.conn.unpublish("said")

    @link.conn.unsubscribe(@sub)

    h = proc { |n| joined(n) }
conn.on_join(&h)
conn.off_join(h)

    Asterism::Connection#on_app_join¶

    on_app_join() { (String node, String app) -> untyped } -> Asterism::Connection

    アプリが来たときに呼ぶブロック

    ブロックは |端末の名前, アプリの名前| で、update の中で呼ばれる。 1 つの端末が複数のアプリを動かしていても、アプリごとに来る・去る。切れたときは、知っていたアプリが全部去る。link_up の中で渡す。

    conn.on_app_join do |n, a|
  seen(n, a)
end

    アプリが去ったときに呼ぶブロック

    conn.on_app_leave do |n, a|
  gone(n, a)
end

    Asterism::Connection#profile¶

    profile(
  ?kind: (Symbol | String)?,
  ?name: String?,
  ?host: String?,
  ?icon: String?
) -> Hash

    この端末の名乗り (種類・名前・アイコン)

    キーワードを渡すとその項目を変えて、全体を返す。渡さなければ今のものを返す。kind: (Symbol か String。nil で既定へ戻す)、name:・host: (String。nil で外す)、icon: (PNG のバイト列。nil でアイコン無し)。受け付けないものは ArgumentError。名乗りは端末のもので、同じ端末のほかの接続にも効く。変えると流れる。

    conn.profile(name: "Rover")

    Asterism::Connection#profile_of¶

    profile_of(
  String node,
  ?icon: bool,
  ?timeout: (Integer | Float)?,
  ?timeout_ms: Integer?
) -> Hash?

    ほかの端末の名乗りを読む

    答えを待つ (既定 2 秒。timeout: は秒、timeout_ms: はミリ秒)。 icon: false でアイコンのバイト列を省く (icon_hash は付く)。つながっていないと Asterism::Disconnected。自分の端末は問い合わせない。

    p = @link.conn.profile_of(node)
name = p["name"] if p

    Asterism::Connection#protocol_of¶

    protocol_of(
  String node,
  ?timeout: (Integer | Float)?,
  ?timeout_ms: Integer?
) -> Integer?

    端末やアプリが話す通信の版

    "端末/アプリ" を渡すとそのアプリの版 (まだ見えていなければ nil)。端末だけなら、そのアプリの版の一番低いもの。アプリが見えない端末は名乗りに聞く (答えなければ nil、版が書いてなければ 0)。自分の版は Asterism::PROTOCOL。

    v = conn.protocol_of("n/app")

    Asterism::Connection#define_type¶

    define_type(
  String | Symbol name,
  Array[Array[untyped]] fields,
  ?desc: String?
) -> Hash

    自分の型を決める

    name は "mygame/board.strokes" のような名前。fields は [[名前, 型], ...] で、型は名前 (組み込みの "vector3"、基本の "int" "float" "str" "bin" "bool" "any"、別の自分の型。末尾に "[]" で配列)。値は欄の名前をキーにした Hash で、名前は短いほど値が小さい。 desc: (省略すると無し) は説明。同じ名前は置き換わる。つながりが閉じても残る。送った定義 ({"f" => ..., "d" => ...}) を返す。数を型にしたり不正な欄だと ArgumentError。publish の type: に名前を渡す。

    conn.define_type("g/pt",
  [["x", "int"], ["y", "int"]])
