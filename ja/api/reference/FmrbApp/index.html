    FmrbApp¶

    アプリの土台。これを継承して書く

    使い方は アプリ、アプリ間通信 のページにあります。

    アプリは class MyApp < FmrbApp と書き、on_create・on_update・on_event など呼ばれるところを書きかえる。ファイルにはクラスを書くだけでよく、読み終えるとそのクラスが作られて start される。

    絵は gfx (@gfx) に描く。@gfx は FmrbApp が用意する FmrbGfx で、原点はアプリが描いてよい区画の左上。描いたら gfx.present で出す。 Window の大きさは window_width・window_height、色は theme_fg などで読む。

    最初に読むとよいメソッド: on_create、on_update、on_event、gfx、 set_timer、publish。

    定数¶

    名前 型 中身
    TRANSPARENT_COLOR Integer 透ける色 (RGB332 の 0x01)

    型¶

    名前 型 中身
    wallclock { year: uint16, month: uint8, day: uint8, hour: uint8, minute: uint8, second: uint8 } wallclock が返す日付と時刻
    sys_pool_info { total: uint32, used: uint32, free: uint32, used_blocks: uint32, free_blocks: uint32 } sys_pool_info が返す本体のメモリのようす
    gfx_stats { cmds: uint32, presents: uint32 } gfx_stats が返す絵を送った回数
    wasm_stats { running: uint8, apps: uint8, modules: uint8, natives: uint16, pool_total: uint32, pool_used: uint32, pool_high: uint32, traps: uint32 } wasm_stats が返す wasm のランタイムのようす
    wasm_app_stats { pages: uint32, max_pages: uint32, binary_size: uint32, hook_us: uint32, hook_max_us: uint32, calls: uint32 } wasm_app_stats が返す wasm のアプリのようす
    event { type: :key_down \| :key_up \| :mouse_down \| :mouse_up \| :mouse_move \| :mouse_wheel \| :gamepad_down \| :gamepad_up \| :gamepad_axis \| :kana_mode, x: int32, y: int32, wx: int32, wy: int32, button: int32, keycode: int32, scancode: int32, modifier: int32, character: int32, delta: int32, gamepad_id: int32, axis: int32, value: int32, mode: int32 } on_event に来る入力

    FmrbApp.clipboard¶

    clipboard() -> String

    クリップボードの文字

    どのアプリとも同じ 1 つのクリップボード。空なら ""。 PC とブラウザ版では、そちらでコピーした文字も入る。 FmrbApp.clipboard(100) のように数を渡すと、そのバイト数までを、文字の途中で切らずに返す。

    text = FmrbApp.clipboard

    FmrbApp.clipboard_raw¶

    clipboard_raw(Integer limit) -> String

    clipboard の省略なしの形

    引数を省略できない単純な形。limit が 0 なら全部、正なら そのバイト数までを、文字の途中で切らずに返す。包みは clipboard (limit を省くと 0)。

    text = FmrbApp.clipboard_raw(0)

    FmrbApp.set_clipboard¶

    set_clipboard(String text) -> bool

    クリップボードに文字を入れる

    64 KB より大きいと入れずに false を返す。

    FmrbApp.set_clipboard("hello")

    FmrbApp.clipboard_gen¶

    clipboard_gen() -> Integer

    クリップボードが変わった回数

    文字を読まずに、変わったかどうかを知るのに使う。

    g = FmrbApp.clipboard_gen

    FmrbApp.notify¶

    notify(String summary, String body) -> bool

    画面の右上に小さな知らせを出す

    数秒で消える。上にアプリの名前、その下に文と本文 (2 行まで)。知らせを出せるのは PC だけで、ほかの端末では何も出さずに false を返す。

    FmrbApp.notify("Saved", "/home/a.txt")

    FmrbApp.notify_raw¶

    notify_raw(String summary, String body) -> bool

    notify の省略なしの形

    引数を省略できない単純な形。包みは notify (body を省くと "")。

    FmrbApp.notify_raw("Saved", "")

    FmrbApp.ps¶

    ps() -> Array

    動いているアプリの一覧

    動いているアプリの一覧。1 つずつが名前と pid を持つ Hash。

    FmrbApp.ps.each do |a|
  Log.info("#{a[:pid]} #{a[:name]}")
end

    FmrbApp.ps_gen¶

    ps_gen() -> Integer

    アプリ一覧が変わった回数

    一覧が変わるたびに増える番号。これが変わったときだけ ps を呼べば、毎フレーム一覧を作らずに済む。

    gen = FmrbApp.ps_gen
list = FmrbApp.ps if gen != @gen

    FmrbApp.checkpoint¶

    checkpoint(Integer pid) -> String?

    別のアプリをイメージに書いて閉じる

    pid のアプリを止めてイメージに書き、閉じるよう頼みます (Shell の checkpoint)。restart: true ならすぐに起動し直します。頼めたら nil、頼めないときは理由の文字列。答えは後から on_control に {"cmd" => "checkpoint_result", "pid", "ok", "path" か "reason"} で届きます。

    FmrbApp.checkpoint(5,
                   restart: true)

    FmrbApp.move¶

    move(Integer pid, String to) -> String?

    別のアプリを別の端末へ移す

    pid のアプリを Asterism の端末 to (ノード ID) へ移すよう頼みます (Shell の move)。頼めたら nil、頼めないときは理由の文字列。答えは後から on_control に {"cmd" => "checkpoint_result", "pid", "ok", "to", "there" と "missing" か "reason"} で届きます。

    FmrbApp.move(5, "fmruby-abcdef")

    heap_info() -> Hash

    空きメモリの様子

    h = FmrbApp.heap_info
Log.info("#{h[:free]} free")

    FmrbApp.last_error¶

    last_error() -> Hash?

    直前に落ちたアプリのエラー

    最後に失敗したアプリの名前とエラーの文を {name:, error:} の Hash で返す。値が入るのは、Ruby のアプリが例外で終わったとき・コンパイルできなかったとき・起動を断られたとき・イメージから戻せなかったときと、Python のアプリを 2 つ目に起動したとき。どのアプリのものでも 1 つだけで、次に失敗したアプリが上書きする。消えることはなく、起動してからまだどのアプリも失敗していなければ nil。 name はアプリの名前 (31 バイトまで)、error は例外の文と、あればその後に 1 行ずつバックトレース (合わせて 1023 バイトまで)。自分のエラーかどうかは name で見分ける。

    e = FmrbApp.last_error
Log.info("#{e[:name]}: #{e[:error]}") if e

    FmrbApp.pool_used¶

    FmrbApp#on_restore¶

    on_restore() -> void

    イメージから起動したとき

    イメージから起動したアプリで、書かれた所から続ける直前に呼ばれます。インスタンス変数も Task もタイマもそのまま戻っています。Window (同じ場所・大きさ・枠、フォント、GfxBlock) と subscribe した知らせは基底クラスが戻してあり、キーボードはこのアプリに来ます。描いた絵は戻りません: Window は枠だけの空の状態なので、何かあったときだけ描くアプリはここで描き直します (on_update で毎回全部描くアプリは何もしなくてよい)。スプライトや画像など、アプリが自分で外に作ったものもここで作り直します。ファイルを開いたままのアプリはイメージに書けません。画面の大きさが違う端末 (Retro と Modern) へ移ると、Window が画面に収まるよう縮められたり、全画面の大きさが変わったりします。そのときは on_restore の前に on_resize が来ます (大きさを変えたときと同じ)。移った先のビルドには、すべての端末に共通でないメソッドが無いことがあります。respond_to? で確認するか rescue NoMethodError で受けてください (端末の違いはアプリの小さな窓口のオブジェクトに集め、そこで respond_to? か method_missing で吸収するのがおすすめ。Array など組み込みのクラスに method_missing を足すのはおすすめしません)。着いた側は足りない名前をログと答えで教えますが、断りません。無いと続けられないメソッドは .app.toml に requires = ["名前"] と書くと、それが無いビルドへは移りません。詳しくは doc/checkpoint/movable_apps.md。

    FmrbApp#on_event¶

    on_event(event ev) -> void

    キーやマウスの入力が来たとき

    ev は入力の中身が入った Hash です。よく使うのは次の 4 つ:

    • ev[:type] … :key_down :mouse_up など、何が起きたか

    class MyApp < FmrbApp
  def on_event(ev)
    return unless
      ev[:type] == :key_down
    case ev[:scancode]
    when 0x4F then @x += 4  # 右
    when 0x50 then @x -= 4  # 左
    end
  end
end
