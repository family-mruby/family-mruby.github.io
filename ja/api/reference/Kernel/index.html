    Kernel¶

    どこからでも呼べる出力・乱数・Proc の道具

    puts の行はログに出る (画面ではない)。print は改行しない。rand は max を省くか 0 で 0 以上 4294967295 以下の整数を返す (CRuby のような小数ではない)。proc・lambda・ -> でブロックを Proc にする。

    定数¶

    名前 型 中身
    MSG_TASK_KERNEL Integer カーネルの task 番号 (0)
    MSG_TASK_HOST Integer ホストの task 番号 (1)
    MSG_TASK_SYSTEM Integer デスクトップ (システムのアプリ) の task 番号 (2)

    クラスメソッド¶

    Kernel.send_message¶

    send_message(
  Integer task_id,
  Integer msg_type,
  String data,
  ?Integer timeout_ms
) -> bool

    待ち行列に生の文字列を送る

    task_id は 0 から上限 (端末で 9) 未満 (範囲の外は ArgumentError)。 data は 64 バイトまで (超えると ArgumentError)。timeout_ms (省略すると 100) は、行列が満杯のときに待つ長さ。

    送れたら true で、行列が無い・満杯のまま timeout_ms が過ぎたときは false (例外は出ない)。

    Kernel.send_message(0, 1, "key_down:13")

    Kernel.receive_message¶

    receive_message(Integer task_id, ?Integer timeout_ms) -> Array[untyped]?

    待ち行列から 1 通取り出す

    [種類, 文字列] の配列を返す。待っても来なければ nil (timeout_ms は省略すると 1000)。task_id が 0 から上限 (端末で 9) 未満の外なら ArgumentError、行列が無いときは RuntimeError で、nil ではない。 アプリ自身の番号を渡すと、_spin が読んでいるのと同じ行列を取り合う。

    msg = Kernel.receive_message(2, 5000)
type, data = msg if msg

    Kernel.broadcast_message¶

    broadcast_message(
  Integer msg_type,
  String data,
  ?Integer timeout_ms
) -> Integer

    全部の待ち行列に送る

    登録されている全部の行列に同じ伝言を入れ、入った数を返す。行列が満杯なら 1 つにつき timeout_ms (省略すると 10) まで待つ。data は 64 バイトまで (超えると ArgumentError)。

    n = Kernel.broadcast_message(99, "bye")

    Kernel.message_queue_exists?¶

    message_queue_exists?(Integer task_id) -> bool

    その task に待ち行列があるか

    task_id が 0 から上限 (端末で 9) 未満の外なら ArgumentError。

    ready = Kernel.message_queue_exists?(0)

    インスタンスメソッド¶

    Kernel#p¶

    p(*untyped objects) -> untyped

    中身が分かる形で出力する

    inspect した形で出す。渡したものがそのまま返るので、式の途中に差し込める。

    p x
y = p compute

    Kernel#print¶

    print(*untyped objects) -> nil

    出力する

    改行しない。

    print "loading"

    Kernel#puts¶

    puts(*untyped objects) -> nil

    改行をつけて出力する

    行はログに出る (画面ではない)。sim なら docker logs fmruby_core、実機ならシリアル。$stdout.puts を呼ぶので書き方は IO#puts と同じ (配列は 1 要素 1 行)。シェルで動かしたスクリプトではシェルの画面に出る。

    puts "started"

    Kernel#rand¶

    rand(?Integer max) -> Integer

    乱数を返す

    max を省くか 0 を渡すと、0 以上 4294967295 以下の整数 (CRuby のような 0 以上 1 未満の Float ではない)。max があれば、0 以上 max 未満の整数 (RNG.random_int % max)。整数だけを受ける (Range・Float は使えない)。種は与えられない (srand は無い)。

    x = rand(10)    #=> 0..9
t = 2000 + rand(4000)

    Kernel#yield¶

    yield(*untyped arguments) -> untyped

    渡されたブロックを呼ぶ

    渡されたブロックを呼ぶ。無いのに呼ぶと落ちるので block_given? で確かめる。

    yield(v) if block_given?

    Kernel#proc¶

    proc() { (untyped argument) -> untyped } -> Proc

    Proc を作る

    外のローカル変数は掴めない (Spinel)。後で呼ぶブロックに渡す値はインスタンス変数か引数にする。

    f = proc { |v| draw(v) }

    Kernel#lambda¶

    lambda() { (untyped argument) -> untyped } -> Proc

    lambda を作る

    proc との違いは引数の数の厳しさと return の効き方。

    f = lambda { |v| v * 2 }

    Kernel#->¶

    ->(untyped argument) { (untyped block_argument) -> untyped } -> Proc

    手続きを短く書く

    lambda の短い書き方。

    f = ->(v) { v * 2 }
f.call(3)
