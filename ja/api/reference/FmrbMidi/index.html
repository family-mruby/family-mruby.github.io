    FmrbMidi¶

    MIDI の入り口。音を出すデバイス・曲・MML

    使い方は MIDI のページにあります。

    FmrbMidi.device(self) で内蔵音源 (APU) につながったデバイス (MIDI::Device) をもらい、 note_on などで音符を送る。標準 MIDI ファイルは FmrbMidi::SmfPlayer、MML は FmrbMidi::MmlPlayer が鳴らす。外の音源へは sam2695_device・serial_device がデバイスを作り、register で出し先を足す。曲の時間は now_us で測る。

    定数¶

    名前 型 中身
    GM_DRUM_CHANNEL Integer ドラムの channel の番号

    クラスメソッド¶

    FmrbMidi.device¶

    device(FmrbApp app) -> MIDI::Device

    このアプリ用の音を出すデバイスを作る

    内蔵音源 (APU) につながったデバイスが返る。外の音源に出すなら出し先を register する。

    @midi = FmrbMidi.device(self)
@midi.note_on(60)

    FmrbMidi.now_us¶

    now_us() -> Integer

    今の時刻 (百万分の一秒)

    音の予定を組むときの時計。曲の時間はこれで測る (描画の回数で数えると重いフレームで狂う)。

    t0 = FmrbMidi.now_us

    FmrbMidi.gm_name¶

    gm_name(Integer program) -> String?

    楽器の番号から名前を引く

    0 から 127 まで。範囲の外は nil。名前は 16 字までに縮めてある (0 番は "Ac Grand Piano")。

    FmrbMidi.gm_name(0)
#=> "Ac Grand Piano"

    FmrbMidi.sam2695_device¶

    sam2695_device(
  ?path: String,
  ?uart: Integer,
  ?tx: Integer,
  ?rx: Integer,
  ?baud: Integer
) -> MIDI::Device?

    外の音源 (SAM2695) のデバイスを作る

    M5Stack Unit MIDI など。シリアルで MIDI を送る (31250 baud)。 つながらなければ nil (sim では受け皿の FIFO が無いとき、実機では端末に MIDI の出口が無いときやピンが使われているとき)。 nil のまま使うと NoMethodError なので、必ず確かめる。つなぐたびに音源へ GM System On を送り全 channel を止めるので、 一度だけ作って持っておく。内蔵音源のデバイス (FmrbMidi.device) とは別物で、SmfPlayer#device= で切り替える。 path: (sim だけ)・uart:・tx: (実機だけ)・rx: (省略すると -1 = 送るだけ)・baud: (省略すると 31250)。省略した分は端末の既定。

    @serial = FmrbMidi.sam2695_device
@serial.program_change(0) if @serial

    FmrbMidi.serial_device¶

    serial_device(
  ?path: String,
  ?uart: Integer,
  ?tx: Integer,
  ?rx: Integer,
  ?baud: Integer
) -> MIDI::Device?

    シリアルの MIDI のデバイスを作る

    sam2695_device と同じで、音源のリセットを送らない版。つながらなければ nil。引数も同じ (path: uart: tx: rx: baud:、省略すると端末の既定)。

    @out = FmrbMidi.serial_device
@out.note_on(60) if @out

    FmrbMidi.scheduler¶

    scheduler() -> untyped

    音の時間割を預かる係を返す

    曲の音は、時刻をつけて C の待ち行列へ渡され、タイマーがその時刻に送る。この係がその行列。アプリが見るのは有無だけで、中の _ で始まるメソッドは使わない。無ければ nil (ホストの試験)。

    puts FmrbMidi.scheduler ? "yes" : "no"

    FmrbMidi.tick¶

    tick() -> void

    予定した音の止め時を見る

    MIDI::Device#trigger の音を止めるのはこれ。毎回の on_update で 1 回呼ぶ。呼ばないと、trigger の音は次の MIDI メッセージまで鳴りっぱなし。内蔵音源 (FmrbMidi.device) もシリアルも、作ったデバイスは全部ここで見る。

    def on_update
  FmrbMidi.tick
  FmrbMidi.tick_delay(100)
end

    FmrbMidi.tick_delay¶

    tick_delay(Integer default_ms) -> Integer

    寝てよい時間 (千分の一秒)

    渡した待ち時間と、予定した音の止め時までの短いほうを返す。 on_update の戻り値にすると、短い音が長く鳴らない。返るのは ms。 0 より小さくはならない。

    def on_update
  FmrbMidi.tick
  FmrbMidi.tick_delay(200)
end
