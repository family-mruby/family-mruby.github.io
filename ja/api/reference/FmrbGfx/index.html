    FmrbGfx¶

    絵を描く画面。図形・文字・画像・スプライト

    使い方は 描画 のページにあります。

    アプリは自分で作らない。FmrbApp が用意する gfx (@gfx) を使う。原点 (0, 0) はアプリが描いてよい区画の左上で、色は RGB332 の数 (FmrbGfx::RED など)。描くメソッドは自分自身を返すので続けて書ける。描いただけでは出ない。フレームの終わりに present を 1 回呼ぶ。

    最初に読むとよいメソッド: clear、fill_rect、draw_text、draw_image、 present。

    定数¶

    名前 型 中身
    FONT_METRICS Hash[Array[untyped], font_metrics] 字の種類ごとの字の幅と行の高さ
    BLACK Integer 黒 (RGB332)
    WHITE Integer 白 (RGB332)
    RED Integer 赤 (RGB332)
    GREEN Integer 緑 (RGB332)
    BLUE Integer 青 (RGB332)
    YELLOW Integer 黄 (RGB332)
    CYAN Integer 水色 (RGB332)
    MAGENTA Integer 紫 (RGB332)
    GRAY Integer 灰色 (RGB332)
    COLOR_BLACK Integer 黒 (RGB332)
    COLOR_WHITE Integer 白 (RGB332)
    COLOR_RED Integer 赤 (RGB332)
    COLOR_GREEN Integer 緑 (RGB332)
    COLOR_BLUE Integer 青 (RGB332)
    COLOR_YELLOW Integer 黄 (RGB332)
    COLOR_CYAN Integer 水色 (RGB332)
    COLOR_MAGENTA Integer 紫 (RGB332)
    COLOR_GRAY Integer 灰色 (RGB332)
    BLEND_ADD Integer 色を加算で混ぜる (blend_rect 用)
    BLEND_XOR Integer 色を XOR で混ぜる (blend_rect 用)

    型¶

    名前 型 中身
    image_info { id: uint16, width: uint16, height: uint16 } create_image が返す絵の番号と大きさ
    file_info { exists: bool, size: uint32 } file_status が返す描画側のファイルのようす
    composite_region { src_x: int16, src_y: int16, dst_x: int16, dst_y: int16, w: int16, h: int16, transparent: bool } 合成する矩形 1 つ (set_composite_regions_raw)
    video_info { width: uint16, height: uint16 } video_open_raw が返す動画の大きさ
    video_status { state: uint8, shown: uint32, dropped: uint32 } 動画の再生のようす
    picture_info { width: uint16, height: uint16, format: uint8, bytes: uint32, mtime: uint32 } picture_info が返す絵の大きさと形
    font_metrics { char_w: Integer, half_w: Integer, kana_w: Integer, line_h: Integer } FONT_METRICS の 1 つの字の種類の寸法 (ドット)

    クラスメソッド¶

    FmrbGfx.rgb_to_332¶

    rgb_to_332(Integer r, Integer g, Integer b) -> Integer

    赤緑青の三つの数から色を作る

    0-255 の 3 つを 1 バイトに落とす。赤と緑は 3 ビット、青は 2 ビットなので、近い色は同じ値になる。細かい階調は出ない。

    結果が 0x01 になる組み合わせは避ける。デスクトップは 0x01 を透明の目印に使っているので、Window が透けて見える。

    FmrbGfx.rgb_to_332(255, 0, 0)  #=> 224

    FmrbGfx.video_control¶

    video_control(:play | :pause | :stop | :rewind action) -> video_status?

    動画を流す・止める

    流せる動画は 1 つ。video_open で開いた動画を操作して、そのあとのようすを返す (返事が無ければ nil)。:stop はファイルを閉じ、canvas には最後の絵が残る。包みは FmrbVideo の play・pause・stop・rewind。

    FmrbGfx.video_control(:play)

    FmrbGfx.video_status¶

    video_status() -> video_status?

    動画の再生のようす

    {state:, shown:, dropped:} か、返事が無ければ nil。state は 0 止まり・ 1 再生中・2 一時停止・3 終わり。shown と dropped は出した・飛ばしたこま数。包みは FmrbVideo#status。

    st = FmrbGfx.video_status

    FmrbGfx.hsv_to_rgb¶

    hsv_to_rgb(Integer h, Integer s, Integer v) -> Array

    色あいと濃さと明るさから色を作る

    h は 0-360、s と v は 0-255。戻り値は [r, g, b] の配列で、そのままでは色として使えない。rgb_to_332 に渡す。

    r, g, b = FmrbGfx.hsv_to_rgb(hue, 255, 255)
color = FmrbGfx.rgb_to_332(r, g, b)

    FmrbGfx#canvas_width¶

    canvas_width() -> Integer

    画面の横幅 (ドット)

    canvas 全体の幅。Window のアプリが描いてよいのは、その内側の区画 (area_width、@user_area_width と同じ) で、canvas_width とは違う。全画面のアプリでは一致する。

    w = @gfx.canvas_width

    FmrbGfx#area_width¶

    area_width() -> Integer

    描く区画の横幅 (ドット)

    原点 (0, 0) から描いてよい幅。アプリの gfx では @user_area_width と同じ。

    w = @gfx.area_width

    FmrbGfx#area_height¶

    area_height() -> Integer

    描く区画の高さ (ドット)

    原点 (0, 0) から描いてよい高さ。area_width と対。アプリの gfx では @user_area_height と同じ。

    @gfx.fill_rect(0, 0, @gfx.area_width,
                @gfx.area_height, 0)

    FmrbGfx#origin_x¶

    origin_x() -> Integer

    原点の canvas 上の x

    描く座標はすべてここに足されて canvas に届く (本体の側で足す)。枠のある Window の gfx は 1、window_gfx などは 0。スプライトの画像へ描いている間は描く座標に足さないが、スプライトの座標 (set_sprite_clip・SpriteInstance) には足す。

    FmrbApp.set_text_cursor(
  @gfx.origin_x + x,
  @gfx.origin_y + y, 12)

    FmrbGfx#origin_y¶

    origin_y() -> Integer

    原点の canvas 上の y

    origin_x の縦の対。描く座標に足されて canvas に届く y 座標の原点で、枠のある Window の gfx は 1、window_gfx などは 0。

    FmrbApp.set_text_cursor(
  @gfx.origin_x + x,
  @gfx.origin_y + y, 12)

    FmrbGfx#clear¶

    clear(Integer color) -> FmrbGfx

    画面ぜんぶを一色でぬる

    canvas 全体を塗る。Window のアプリで呼ぶと、自分で描いたタイトルバーもわくも消える。Window の中だけを消すなら FmrbApp#clear_user_area を使う。あちらはわくを描き直し、付いている FmrbUI の部品にも描き直しの印を付ける。

    全画面のアプリなら clear でよく、fill_rect で同じ範囲を塗るより速い。

    @gfx.clear(FmrbGfx::BLACK)
@gfx.present

    FmrbGfx#set_pixel¶

    set_pixel(Integer x, Integer y, Integer color) -> FmrbGfx

    点を一つ打つ

    gfx.set_pixel(10, 20,
              FmrbGfx::WHITE)

    FmrbGfx#get_pixel¶

    get_pixel(Integer x, Integer y) -> Integer

    点の色を読む

    描画側への同期的な往復になる。1 画素ずつ読んで画面を走査するような使い方には向かない。

    canvas の外を指すと 0 を返す。0 は黒でもあるので、範囲外と黒は戻り値では区別できない。

    c = @gfx.get_pixel(60, 40)
# canvas の外は 0

    FmrbGfx#draw_line¶

    draw_line(
  Integer x0,
  Integer y0,
  Integer x1,
  Integer y1,
  Integer color
) -> FmrbGfx

    まっすぐな線を引く

    gfx.draw_line(0, 0, 100, 60,

    FmrbGfx#draw_thick_line¶

    draw_thick_line(
  Integer x0,
  Integer y0,
  Integer x1,
  Integer y1,
  Integer thickness,
  Integer color
) -> FmrbGfx

    太さのある線を引く

    描画側に太い線の命令が無いので、1 画素の線を thickness 本だけずらして重ねている。太さの分だけ命令が増えるので、太い線を毎フレーム引くと効く。

    @gfx.draw_thick_line(10, 10, 60, 40,
                    2, FmrbGfx::WHITE)

    FmrbGfx#draw_rect¶

    draw_rect(
  Integer x,
  Integer y,
  Integer w,
  Integer h,
  Integer color
) -> FmrbGfx

    四角のふちを描く

    (x, y) は左上の角、w は横幅、h は高さです。線だけを描くので、中は下にあるものが見えたままになります。中もぬりたいときは fill_rect を使います。

              FmrbGfx::WHITE)  # わく

    FmrbGfx#picture_info¶

    picture_info(String path) -> picture_info?

    絵のファイルの大きさを読む

    FmrbGfx#draw_picture¶

    draw_picture(String path, Integer x, Integer y) -> bool

    絵のファイルを描く (無ければ読む)

    パス (か put_picture の名前) を渡すだけでよい。初めての絵は描画側のスプライトの絵に読み、この FmrbGfx が picture_limit 枚 (既定 8) まで持つ。超えたら最近使っていないものから離す。ファイルを書き換えると (大きさか時刻が変わると) 次に描くときに読み直す (見に行くのは 1 秒に 1 回まで)。アプリが終わると全部離れる。

    • scale: 1〜32 は元の 1 点を scale x scale に、-2〜-32 は 1/|scale| に
    • checker: true で透明の所に市松を敷く (draw_checker)
    • clip: [x, y, w, h] でその矩形の中だけ描く

    描けなければ false (落ちない)。理由は picture_error。65,536 点を超える絵は断る。65,536 バイトを超えるファイルはアプリの側で読んで (BMP332.load、読む間は VM プールに載る) 画素を置く。透明は 0x01 の色 (PNG の α・tRNS)。

    gfx.draw_picture("/home/stamps/a.png",
  10, 20, scale: 2)
gfx.draw_picture(path, 0, 0,
  scale: -2, checker: true)

    FmrbGfx#present¶

    present() -> FmrbGfx

    描いたものを画面に出す

    描くメソッドは命令を積むだけで、画面には出ない。present を呼んだときにまとめて送られ、そこで初めて出る。スプライトの合成も present の時に走るので、 SpriteInstance#move や visible= の後にも要る。

    FmrbGfx#sync_file¶

    sync_file(String path, ?dest: String) -> bool

    絵や音のファイルを送る

    描画側は自分のファイルシステムしか読めないので、素材は先に送っておく。大きさと CRC32 を比べて、違うときだけ送る。毎回呼んでよい。
