    P5¶

    p5.js 風の書き方で絵を描く

    使い方は Processing 風の描画 のページにあります。

    @p5 = P5.new(@gfx) で作る。FmrbGfx を包むだけなので、同じ絵に両方から描いてよい。 fill・stroke で色を決めてから rect・circle・line・text などで形を描き、最後に present で出す。background で塗りつぶす。ふちだけにするなら no_fill。

    定数¶

    名前 型 中身
    BLACK Integer 黒 (RGB332)
    WHITE Integer 白 (RGB332)
    RED Integer 赤 (RGB332)
    GREEN Integer 緑 (RGB332)
    BLUE Integer 青 (RGB332)
    YELLOW Integer 黄 (RGB332)
    CYAN Integer 水色 (RGB332)
    MAGENTA Integer 紫 (RGB332)
    GRAY Integer 灰色 (RGB332)
    REPLACE Integer ふつうに上書きする (0)
    ADD Integer 明るく重ねる (1)
    XOR Integer 反転して重ねる (2)

    クラスメソッド¶

    P5.new¶

    new(FmrbGfx gfx) -> P5

    p5 の書き方の道具を作る

    FmrbGfx を包むだけなので、同じ絵に P5 と FmrbGfx の両方から描いてよい。

    @p5 = P5.new(@gfx)

    インスタンスメソッド¶

    P5#width¶

    width() -> Integer

    画面の横幅 (ドット)

    cx = @p5.width / 2

    P5#height¶

    height() -> Integer

    画面の高さ (ドット)

    cy = @p5.height / 2

    P5#background¶

    background(Integer color) -> void

    画面ぜんぶを色でぬる

    毎フレームの初めに呼んで前の絵を消す。blend_mode を入れていると消さずに重ねる。

    @p5.background(FmrbGfx::BLACK)

    P5#present¶

    present() -> void

    描いたものを画面に出す

    呼ぶまで画面に出ない。1 フレームの描き終わりに 1 回だけ。

    @p5.present

    P5#commit¶

    commit() -> void

    present の別名

    @p5.commit

    P5#fill¶

    fill(Integer color) -> void

    中をぬる色を決める

    以後に描く形の中の色。色は RGB332 の 1 バイト。

    @p5.fill(FmrbGfx::RED)
@p5.circle(60, 60, 20)

    P5#no_fill¶

    no_fill() -> void

    中をぬらないようにする

    ふちだけの形になる。

    @p5.no_fill
@p5.rect(10, 10, 40, 20)

    P5#stroke¶

    stroke(Integer color) -> void

    ふちの色を決める

    @p5.stroke(FmrbGfx::WHITE)

    P5#no_stroke¶

    no_stroke() -> void

    ふちを描かないようにする

    中だけぬった形になる。

    @p5.no_stroke

    P5#stroke_weight¶

    stroke_weight(Integer w) -> void

    ふちの太さを決める

    太い線は細い線を重ねて描くので、太くするほど遅くなる。

    @p5.stroke_weight(3)

    P5#blend_mode¶

    blend_mode(Integer mode) -> void

    色の重ね方を決める

    P5::ADD は明るく重ね、P5::XOR は反転して重ねる。0 で元に戻す。

    @p5.blend_mode(P5::ADD)

    P5#alpha¶

    alpha(Integer value) -> void

    透け具合を決める (今は効かない)

    今は何もしない。p5.js から写した書き方をそのまま通すために置いてある。重ねたいときは blend_mode。

    @p5.alpha(128)  # 効かない

    P5#color¶

    color(Integer r, Integer g, Integer b) -> Integer

    赤緑青の三つの数から色を作る

    0 から 255 の三つを 1 バイトに縮める。赤緑は 8 段、青は 4 段に丸められる。

    c = @p5.color(255, 128, 0)

    P5#point¶

    point(Integer x, Integer y) -> void

    点を一つ打つ

    stroke の色で打つ。no_stroke のときは何も出ない。

    @p5.point(10, 20)

    P5#line¶

    line(Integer x0, Integer y0, Integer x1, Integer y1) -> void

    線を引く

    @p5.line(0, 0, 100, 60)

    P5#rect¶

    rect(Integer x, Integer y, Integer w, Integer h) -> void

    四角を描く

    左上の角と大きさで指す。

    @p5.rect(10, 10, 40, 20)

    P5#circle¶

    circle(Integer cx, Integer cy, Integer r) -> void

    円を描く

    真ん中と半径で指す。

    @p5.circle(60, 60, 20)

    P5#ellipse¶

    ellipse(Integer cx, Integer cy, Integer rx, Integer ry) -> void

    だ円を描く

    @p5.ellipse(60, 60, 30, 15)

    P5#triangle¶

    triangle(
  Integer x0,
  Integer y0,
  Integer x1,
  Integer y1,
  Integer x2,
  Integer y2
) -> void

    三角を描く

    @p5.triangle(10, 50, 30, 10,
             50, 50)

    P5#quad¶

    quad(
  Integer x0,
  Integer y0,
  Integer x1,
  Integer y1,
  Integer x2,
  Integer y2,
  Integer x3,
  Integer y3
) -> void

    四つの点で四角を描く

    点は順につながる。交差する順で渡すと形が崩れる。

    @p5.quad(10, 10, 50, 14,
         48, 40, 12, 36)

    P5#arc¶

    arc(
  Integer cx,
  Integer cy,
  Integer r,
  Integer start_angle,
  Integer stop_angle
) -> void

    円の一部の弧を描く

    角度はラジアン (0 が右、時計回り)。

    @p5.arc(60, 60, 30,
        0, Math::PI / 2)

    P5#bezier¶

    bezier(
  Integer x1,
  Integer y1,
  Integer x2,
  Integer y2,
  Integer x3,
  Integer y3,
  Integer x4,
  Integer y4
) -> void

    なめらかな曲線を描く

    始点・引く点 2 つ・終点。線を 20 本に割って描くので、 no_stroke では何も出ない。

    @p5.bezier(10, 60, 30, 10,
           70, 10, 90, 60)

    P5#curve¶

    curve(
  Integer x1,
  Integer y1,
  Integer x2,
  Integer y2,
  Integer x3,
  Integer y3,
  Integer x4,
  Integer y4
) -> void

    点をつないだ曲線を描く

    真ん中の 2 点の間だけが描かれる。両端は曲がり方を決めるだけ。

    @p5.curve(0, 60, 10, 60,
          90, 60, 100, 60)

    P5#begin_shape¶

    begin_shape() -> void

    自由な形を描き始める

    vertex で角を足し、end_shape で閉じる。

    @p5.begin_shape
@p5.vertex(10, 10)
@p5.vertex(40, 20)
@p5.vertex(20, 40)
@p5.end_shape(true)

    P5#vertex¶

    vertex(Integer x, Integer y) -> void

    形の角の点を足す

    begin_shape の前に呼んでも黙って捨てられる。

    @p5.vertex(40, 20)

    P5#end_shape¶

    end_shape() -> void

    自由な形を描き終える

    true を渡すと閉じた形になる。中をぬるには角が 3 つ以上要る。

    @p5.end_shape(true)

    P5#text¶

    text(String str, Integer x, Integer y) -> void

    字を描く

    色は fill ではなく text_color。位置は text_align に従う。

    @p5.text("Hello", 10, 20)

    P5#text_font¶

    text_font(Symbol font) -> void

    字の種類をえらぶ

    :default が英数字、:ja で日本語が出せる (大きさは 8 になる)。

    @p5.text_font(:ja)
@p5.text("こんにちは", 10, 20)

    P5#text_color¶

    text_color(Integer color) -> void

    字の色を決める

    @p5.text_color(FmrbGfx::WHITE)

    P5#text_align¶

    text_align(Symbol horizontal) -> void

    字をそろえる場所を決める

    横は :left :center :right、縦は 2 つめの引数で :top :center :bottom。

    @p5.text_align(:center, :center)

    P5#text_leading¶

    text_leading(Integer pixels) -> void

    行と行の間を決める

    @p5.text_leading(12)

    P5#text_width¶

    text_width(String str) -> Integer

    字を描いたときの横幅を測る

    今えらんでいる字の種類で測る。中央ぞろえを自分で計算するときに使う。

    w = @p5.text_width(s)

    P5#translate¶

    translate(Integer tx, Integer ty) -> void

    描く場所をずらす

    以後の描画すべてがずれる。元に戻すには push_matrix と組で使う。

    @p5.push_matrix
@p5.translate(60, 60)
@p5.circle(0, 0, 10)
@p5.pop_matrix

    P5#rotate¶

    rotate(Integer angle) -> void

    描くものを回す

    ラジアンで、原点のまわりに回す。物のまわりで回すには先に translate する。

    @p5.translate(60, 60)
@p5.rotate(Math::PI / 4)

    P5#scale¶

    scale(Integer sx) -> void

    描くものを大きくする

    縦横を別々にもできる (2 つめの引数)。1.0 が元の大きさ。

    @p5.scale(2.0)
@p5.scale(2.0, 0.5)

    P5#push_matrix¶

    push_matrix() -> void

    今のずらし方を覚えておく

    pop_matrix と必ず組にする。積んだままだとずれが残る。

    @p5.push_matrix

    P5#pop_matrix¶

    pop_matrix() -> void

    覚えたずらし方に戻す

    積んでいないときに呼んでも何も起きない。

    @p5.pop_matrix

    P5#reset_matrix¶

    reset_matrix() -> void

    ずらし方をぜんぶ元に戻す

    @p5.reset_matrix

    P5#set_pixel¶

    set_pixel(Integer x, Integer y, Integer color) -> void

    点を一つ打つ

    ずらし方 (translate や rotate) を通さない。画面そのままの座標。

    @p5.set_pixel(10, 20, c)

    P5#get_pixel¶

    get_pixel(Integer x, Integer y) -> Integer

    点の色を読む

    返事を待つので遅い。ループの中で何度も読まない。

    c = @p5.get_pixel(10, 20)

    P5#image¶

    image(Integer image_id, Integer x, Integer y) -> void

    読み込んだ絵を描く

    id は FmrbGfx で読み込んだ絵の番号。4 つめ 5 つめで拡大できる。

    @p5.image(id, 10, 20)
@p5.image(id, 10, 20, 2.0, 2.0)

    P5#image_masked¶

    image_masked(
  Integer image_id,
  String mask_data,
  Integer x,
  Integer y,
  Integer w,
  Integer h
) -> void

    型でぬいた形の絵を描く

    型は 1 ビットずつの白黒で、1 のところだけ絵が出る。

    @p5.image_masked(id, mask,
                 10, 20, 16, 16)
