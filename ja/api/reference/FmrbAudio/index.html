    FmrbAudio¶

    音を鳴らす。曲・効果音・WAV・マイク

    使い方は 音声 のページにあります。

    アプリは @audio = FmrbAudio.new(self) で作る。NSF の曲は play (止めるのは stop、一時停止は pause・resume)、WAV は play_wav、音を 1 つずつなら note_on・note_off、 FMSQ のデータは load_fmsq で読んで play_slot。マイクは mic_available? で調べて mic_enable・mic_read で読む。MIDI の音符を送るなら FmrbMidi。

    定数¶

    名前 型 中身
    NSF_IDLE Integer state 0: 曲が無い・命令で止めた
    NSF_PLAYING Integer state 1: 鳴っている
    NSF_FADING Integer state 2: 終わりを見つけて小さくしている
    NSF_ENDED Integer state 3: 曲が自分で終わった
    NSF_END_SILENCE Integer reason 1: 無音で終わった
    NSF_END_LOOP Integer reason 2: ループを聞き終えて終わった
    NSF_END_LIMIT Integer reason 3: 時間の上限で終わった
    MAIN Integer 長い曲を置く APU (0)
    SUB Integer 効果音の APU (1)
    CH_PULSE1 Integer 矩形波 1 の channel (0)
    CH_PULSE2 Integer 矩形波 2 の channel (1)
    CH_TRIANGLE Integer 三角波の channel (2)
    CH_NOISE Integer ノイズの channel (3)

    型¶

    名前 型 中身
    nsf_status { state: uint8, reason: uint8, track: uint8, laps: uint8, gen: uint16, period: uint16, frames: uint32 } nsf_status が返す曲のようす

    FmrbAudio#play¶

    play(String path, ?track: Integer) -> void

    曲のファイルを鳴らす

    NSF を鳴らす。曲は /usr/share/sounds/nsf にある。track: (省略すると 0) は NSF の中の曲の番号。

    @audio.play("/usr/share/sounds/nsf/test.nsf")

    FmrbAudio#play_raw¶

    play_raw(String path, Integer track) -> void

    play の省略なしの形

    引数を省略できない単純な形。track は NSF の中の曲の番号 (0 から)。包みは play (track: を省くと 0)。

    @audio.play_raw("/usr/share/sounds/nsf/test.nsf", 0)

    FmrbAudio#stop¶

    stop() -> void

    曲を止める

    @audio.stop

    FmrbAudio#nsf_status¶

    nsf_status() -> nsf_status?

    曲がどこまで進んだかを聞く

    NSF には長さが無いので、音の側が曲の終わりを決める (無音・ループを 2 周・時間の上限)。終わった曲は音の側で止まる。1 秒に 1 回ほど聞いて、終わっていたら次の曲へ進む。答えが無いときは nil。

    st = @audio.nsf_status
next_song if st && st[:state] == FmrbAudio::NSF_ENDED

    FmrbAudio#mic_available?¶

    mic_available?() -> bool

    マイクがあるか

    ESP32-P4 の端末 (Tab5 など) だけ true。それ以外は false なので、呼ぶ前に端末を調べなくてよい。

    return unless @audio.mic_available?

    FmrbAudio#mic_rate¶

    mic_rate() -> Integer

    マイクの標本化の速さ (Hz)

    ESP32-P4 では 47160 (スピーカーと同じクロックで、選べない)。マイクの無い端末では 0。スペクトルの 1 本の幅 (Hz) はこれを標本の数で割る。

    hz = @audio.mic_rate

    FmrbAudio#mic_enable¶

    mic_enable(?bool on) -> bool

    マイクを入れる・切る

    on (省略すると true)。読む前に入れ、使い終えたら false で切る。成功したら true。マイクの無い端末や、立ち上げに失敗したときは false (例外は出ない)。すでにその状態なら true。

    @audio.mic_enable
@audio.mic_enable(false)

    FmrbAudio#mic_read¶

    mic_read(Integer count, ?Integer timeout_ms) -> String?

    マイクの音を標本で読む

    count 個 (1〜4096、外れると ArgumentError) の 16 ビット符号つき・リトルエンディアンの標本を、2 * count バイトの String で返す。そろうまで待つ (止まる)。timeout_ms (省略すると 200) は、ドライバが 256 個ほどずつ渡すその 1 回ごとの待ち。そろわなかったときと、マイクが入っていない・無いときは nil (半端な長さは返さない)。

    bytes = @audio.mic_read(512, 300)
return if bytes.nil?

    FmrbAudio#play_slot¶

    play_slot(Integer slot_id, ?instance: Integer) -> void

    箱に入れた曲を鳴らす

    instance: (省略すると MAIN) は鳴らす APU で、FmrbAudio::MAIN か FmrbAudio::SUB。

    @audio.play_slot(0)

    FmrbAudio#play_slot_raw¶

    play_slot_raw(Integer slot_id, Integer instance) -> void

    play_slot の省略なしの形

    引数を省略できない単純な形。instance は鳴らす APU で、MAIN (0) か SUB (1)。長い曲は MAIN、短い効果音は SUB に置くと、効果音が曲を切らない。包みは play_slot (instance: を省くと MAIN)。

    @audio.play_slot_raw(0, FmrbAudio::SUB)

    FmrbAudio#main_volume=¶

    main_volume=(Integer percent) -> void

    曲 (MAIN) だけの音量を変える

    0〜100 (%)、最初は 100。play と MAIN の play_slot の曲だけが変わり、効果音 (SUB)・WAV・端末の音量はそのまま。アプリを閉じると 100 に戻る。

    @audio.main_volume = 30

    FmrbAudio#play_wav¶

    play_wav(String path) -> bool

    録音した音 (WAV) を鳴らす

    モノラル・8000〜48000Hz・2MB まで。PCM 16bit か IMA-ADPCM 4bit。APU の音に重ねて鳴る。一度に鳴らせるのは 1 本で、鳴っている間にもう一度呼ぶと入れ替わる。 Retro では鳴らせないので false を返す (鳴ったときは true)。

    ok = @audio.play_wav("/home/a.wav")
# Retro では false

    FmrbAudio#note_on¶

    note_on(
  Integer channel,
  Integer freq,
  ?Integer volume,
  ?Integer duty,
  ?Integer sweep
) -> void

    音を一つ鳴らす

    周波数を Hz で渡す。曲を鳴らしている最中でも重なる。 volume (省略すると 10) は 0〜15、duty (省略すると 2) は矩形波の幅 0〜3、 sweep (省略すると 0)。

    @audio.note_on(0, 440)

    FmrbAudio#note_on_raw¶

    note_on_raw(
  Integer channel,
  Integer freq,
  Integer volume,
  Integer duty,
  Integer sweep
) -> void

    note_on の省略なしの形

    引数を省略できない単純な形。曲の中で何度も鳴らすような、速さが要る所で使う。volume は 0〜15 (包みは 10)、duty は矩形波の幅 0〜3 (包みは 2)、 sweep は 0 (包みと同じ)。包みは note_on。

    @audio.note_on_raw(0, 440, 10, 2, 0)
